## 결론

현재 확인된 공개 자료만으로는 사용자가 지정한 15개 매체를 비교하는 편향 좌표 모델을 학습·검증할 수 없다. 실제 데이터 없이 성능이나 매체 좌표를 만들지 않는다. 기존 UI는 계산 대기 상태를 유지한다.

## 모델 구현 전 통과 조건

1. 대상 매체가 실제로 사용자 지정 15개 후보와 연결되는지 확인할 수 있어야 한다. 출처 매체 이름과 원문 URL, 게시 날짜, 주제·명제, 원본/전재 그룹을 남긴다.
2. 기사 본문 저장·모델 학습·평가·공개 배포의 사용 조건을 각각 확인한다. 불명확하면 본문을 가져오거나 학습 데이터에 넣지 않는다.
3. 같은 기간·주제 안에서 매체별 기사 표본을 구성하고, 반복 보도·동일 원본·본문 중복을 한 그룹으로 표시한다.
4. 모델 축은 매체 기사 표현으로 산출한다. Claude가 기록한 좌익 4곳·우익 3곳 기준은 부호와 분리 여부 검증에만 사용한다. 축을 학습하는 라벨로 다시 쓰지 않는다.
5. 같은 매체가 학습과 평가 양쪽에 포함되도록 원본 그룹 단위로 분리한다. 매체별 분류 성능, 기사 그룹 간 누수 검사, 좌표 재현성·불확실성 및 좌익/우익 중심 분리 결과를 보고한다. 기준 실패 시 계산을 보류한다.
6. 학습 데이터 계보·라이선스·매체별 건수·분리 ID·모델 버전·측정 결과를 공개 가능한 형태로 기록하고, 실제 매체 라벨과 가상 시험 자료를 분리한다.

현재 `research/engine.py`는 `expression_binary` 분류기다. 편향용 별도 파이프라인 `research/train_bias.py`는 매체 식별 SVM·상대 좌표·원본 그룹 분리 평가·추론 JSON 출력을 구현했다. 실제 기사 표본과 독립적인 사람의 축 검토가 없어 실측 모델은 아직 생성하지 않았다. 실행 계약은 `research/BIAS_PIPELINE.md`를 따른다.

## 사이트 연결 상태

- `lib/bias-model.ts`가 오프라인 Python과 같은 문자 TF-IDF·선형 투영을 계산한다. Unicode 문자와 공백 처리를 포함한 추론 수치 일치를 검증했다.
- `lib/data/bias-model.json`은 현재 `null`이다. 실제 이용 조건·분리 평가·사람의 축 검토를 통과한 산출물만 여기에 넣고 다시 빌드한다. 합성·연구용 모델과 버전이 다른 검토 기록은 로더가 거부한다.
- 자동 조사 서버는 검증된 모델의 정확한 비교 명제와 일치하는 본문에만, 발췌 전 좌표를 계산해 기존 서명된 취득 결과에 포함한다. 추가 API·검색·모델 호출은 하지 않는다.
- 현재 분석 ID·명제·모델 버전·평가 공간이 일치하고 원문 인용이 확인된 기사만 메인 게이지 입력에 연결한다. 붙여 넣은 대상 기사는 매체명이 없어도 추론하지만 기준 기사에는 포함하지 않는다. KBS·MBC 등 하위 도메인은 후보 매체와 연결하고, 완전한 동일 본문 해시는 한 원본으로 센다.
- 현재 자동 검색은 호출당 본문 2개 상한을 유지한다. 같은 분석·비교 명제에 대한 서로 다른 사실 주장의 최신 조사 결과는 함께 사용할 수 있다. 모의 응답으로 3개 주장에서 매체 2곳×기사 3개를 모아 준비 상태가 되는 경로와, 한 주장 재조사 실패 시 이전 자료를 빼고 표본 부족으로 돌아가는 경로를 검증했다. 실제 조사에서 이 수와 분포를 확보한다는 보장은 없고, 실제 학습 모델도 아직 없다. 코드 연결 완료를 실측 편향 기능 완료로 보지 않는다.

- [PoliticalK.O 원 저장소](https://github.com/seungukyu/PoliticalK.O), [원 논문](https://aclanthology.org/2025.findings-emnlp.1199/): 2024년 정치 기사와 댓글을 모은 공격적 표현 연구다. README가 설명하는 라벨은 댓글의 공격성 판단이며 매체 상대 좌표 정답이 아니다. 확인한 저장소 루트에는 README와 일부 주제 디렉터리가 있고 별도 LICENSE 파일이 없었다. 대상 매체별 기사 원문·URL·배포 조건과 기사 수준의 평가 라벨을 확인하지 못했으므로 편향 모델 자료로 사용하지 않았다. 댓글을 원 기사 편향 라벨로 치환하지 않는다.

이 검토는 공개된 데이터 카드·저장소 메타데이터를 확인한 결과다. 새로운 실측 모델·정확도·매체 좌표가 생겼다는 뜻은 아니다. 현재 생산용 모델 입력은 계속 `null`이다.
