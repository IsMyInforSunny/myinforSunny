# 라벨 지침 초안 v1

현재 첫 학습 과제는 문장 표현의 이진 분류입니다. 논점·찬반·근거 충분성은 별도 라벨이며 이 파일의 라벨로 대체하지 않습니다.

- clear: 정의한 공격적 표현 기준에 해당하는 명확한 근거가 없음. 안전·중립·사실임을 보장하지 않음.
- flagged: 인신공격·집단 일반화·조롱·위협 등 기준에 해당하는 원문과 문맥을 확인할 수 있음.
- 판단이 어려운 인용·반어·농담·문맥 부족은 초안에서 undetermined로 기록하고 이진 학습에 강제로 넣지 않음. 이진 학습 JSONL에는 조정 완료 clear/flagged만 포함.

문장만으로 판단할 수 없으면 앞뒤 문맥을 확인합니다. 욕설을 인용해 비판한 글과 직접 공격을 구별하고, 비동의·부정적 감정만으로 flagged를 부여하지 않습니다. 기준 ID·근거 구간·라벨 이유·검토자를 별도 이력에 남깁니다.
AI 작성 초안은 draft입니다. 실제 사람의 독립 검토 또는 공개 자료의 원래 라벨 계보를 확인하기 전 reviewed로 바꾸지 않습니다. 두 개의 가짜 검토자 ID를 만들지 않습니다.

공통 JSONL 계약은 기술명세 v3을 따릅니다. engine.py의 첫 표현 실험은 `embeddingVersion`과 `embedding`을 요구합니다. 사용한 encoder의 ID·revision·입력 형식·pooling·정규화는 해당 버전의 별도 model card에 명시합니다.

최초 데이터 후보 조사:

- [KOLD](https://github.com/boychaboy/KOLD): 공개 사람 라벨·공격성 구간·원시 평가자 기록을 제공. 본 프로젝트 기준과의 매핑, 자료 사용·재배포 조건, 스레드 그룹 재구성 확인 후 사용 결정.
- [UnSmile](https://github.com/smilegate-ai/korean_unsmile_dataset): 다중 라벨 한국어 자료. 데이터는 CC-BY-NC-ND 4.0이고 코드·baseline과 라이선스가 다르므로 공개 변형 자료 배포를 자동 허용한다고 간주하지 않음.

이 후보를 이미 학습에 사용했다는 뜻은 아닙니다. 기존 공개 라벨은 표현의 일부 과제에만 적합하며 세 축 전체의 정답이 아닙니다. 출처·권리·도메인 차이를 검토하고 범위에 맞는 독립 시험을 구성합니다.
