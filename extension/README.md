# 선택 텍스트 연결 시제품

개발용 Chromium 확장입니다. 확장 관리 화면의 개발자 모드에서 이 폴더를 ‘압축해제된 확장’으로 로드합니다. 로컬 사이트는 `http://127.0.0.1:4173`에서 실행해야 합니다.

공개 페이지에서 텍스트를 선택하고 확장을 열면 전송 내용 미리보기가 나옵니다. 버튼을 누르면 분석 페이지로 이동하며 사용자가 분석 버튼을 눌러야 API 요청을 보냅니다. 주소 조각은 화면에서 즉시 제거하며 서버 쿼리에 원문을 넣지 않습니다. 브라우저 이동 기록에 잠시 포함될 가능성이 있으므로 민감한 글에는 사용하지 마세요.

공용 비밀키·광범위 사이트 권한·자동 수집·중앙 저장은 없습니다. 이 버전은 로컬 연결 시제품으로 웹스토어 출시나 비공개 배포 사이트의 인증 처리를 완료한 확장이 아닙니다.
