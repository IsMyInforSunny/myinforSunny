## 분석과 수치

입력은 본문 2,000자, 댓글 5개×200자, 선택 명제 160자다. 전체 처리 단위는 24개 이하. 긴 문장은 약 500 UTF-16 단위로 분할하며 최대 8개의 끝 문장부호 예외를 둔다. 처리 단위와 자연 문장은 다르다. `sentence-3.1`은 원문 위치를 보존한다. 이전 구간으로 만들어진 결과는 다시 분석해야 한다.

본문의 모든 처리 단위에 `bodyTopicAssignments`를 만들고 자연 문장별로 합친다. 누락·중복·알 수 없는 논점은 판단 유보 처리한다. 본문과 댓글을 분리한다. 한 문장이 여러 논점에 해당하면 비율의 합이 100%를 넘을 수 있다. 분모에는 기타·유보를 포함한다. 표현 검토 건수 역시 긴 문장의 조각을 중복 집계하지 않는다. 분모 10 미만이면 퍼센트를 표시하지 않는다. FOMO는 규칙으로 찾은 표현 후보·해당 자연 문장 수와 분모를 표시한다. 공격성은 표현 검토 기준에 포함하며 별도 진실 확률·고정 편향 점수는 반환하지 않는다.

신뢰성은 추출된 사실 주장 최대 5개를 대상으로 한다. 조사 완료·미확인·뒷받침·상충·불충분·실제 취득 출처 수를 표시한다. 추출 누락 가능성과 전체 기사 미검증 한계를 알린다. 도메인 수를 독립 근거 수로 해석하지 않는다.

매체 좌표는 동일 명제의 기사별 관측 입장(반대 −1, 맥락 보충 0, 찬성 +1)을 사용한다. 매체별 고유 기사 3개 이상, 적격 매체 2곳 이상이면 매체 평균을 동일 가중치로 합쳐 잠정 기준선을 만든다. 사용자가 직접 지정한 입력 입장과 기준선의 절대 차이를 0–2로 표시한다. 자료 부족은 계산 대기다. 다른 분석 ID·가상 자료·다른 명제를 섞지 않으며 가상 체험은 별도 모드다. 이 값은 언론사의 정치 성향·객관성·중립성·신뢰도 인증이 아니다.

URL 별칭은 한 기사로 세고 분류 충돌이 있으면 집계를 유보한다. 같은 매체·명제 안에서 200자 이상인 취득 본문 전체의 해시·길이·추출 버전·취득 잘림 여부가 확인된 동일 본문은 다른 URL도 한 기사로 묶는다. 발췌 인용만 같거나 취득 단계에서 잘렸거나 동일성 정보가 없는 결과는 본문 중복으로 확정하지 않는다. 중복 주소 수와 분류 유보·표본 부족을 화면에 표시한다. 다른 매체의 동일 본문은 각 매체 관측으로 남으며 독립성의 증거가 아니다.

## API와 자동 조사

기존 `/api/analyze`, `/api/verify`, `/api/capabilities`, `/api/health`, `/api/news`를 유지한다. `/api/research`는 다음 세 작업을 받는다.

1. `plan`: 개인정보·인용·처리 단위를 검증하고 사실 주장별 검색어 최대 5개와 관점 검색어 최대 1개를 계획한다. 직접 지정한 비교 명제가 있으면 추출 의견보다 우선한다. 사실 주장이 없어도 명제만 관점 탐색할 수 있으며 명제의 원문 인용이나 사실 주장을 만들지 않는다. 원문·주장·비교 명제 해시, 호출자와 만료 시간을 서버 서명에 묶는다.
2. `discover`: 서명된 계획의 검색어만 실행한다. 고정 검색 엔드포인트를 사용하고 운영자가 허용한 정확한 호스트만 본문을 취득한다. 리다이렉트를 따르지 않는다. 주장당 최대 2개, 각 최대 1,500자 발췌를 만든다. 원문 위치·추출 버전·해시·취득 시각·실패 이유를 남긴 서명 자료를 브라우저 메모리에 반환한다.
3. `compare`: 서명·호출자·입력 해시를 확인한 자료만 `web_fetched`로 대조한다. 모델은 자료 문장 ID를 고르고 서버가 인용과 위치를 복원한다. 동일 문장 반복 시에도 선택한 위치를 유지한다. 제안에 대한 명시적 입장은 사실 수치 상충과 별도로 분류한다.

자동 단계는 별도 공개 자료 검색·전송 동의 후 실행한다. 무료 모델 예산을 지키기 위해 모델 호출 사이 약 61초를 기다릴 수 있다. 취소·입력 변경 시 후속 호출과 늦은 응답 반영을 막는다. 입력을 원상복구해도 자동 재호출하지 않으며 새 조사 준비·동의·명시적 시작을 요구한다. 취소·실패·자료 없음은 완료로 세지 않는다. 부분 결과는 유지한다. 현재 분석에 연결된 결과만 메인 지표·조사 패널·추천·좌표·내보내기에 반영한다. 출처 있는 다른 입장은 실제 취득 본문 인용이 일치할 때만 표시한다. 기사 본문 전체를 화면에 복제하지 않고 제목·링크·짧은 인용만 표시한다.

본문 취득은 정확한 허용 호스트·리다이렉트 미추적·응답 크기 제한을 유지한다. 직접 취득 HTML은 BOM→HTTP charset→HTML 선언 순으로 해독하고 article·main 본문 후보를 선택한다. 스크립트·주석의 가짜 메타데이터를 제외하며 발행일을 본문 날짜나 수정일로 추정하지 않는다. 이는 출처별 검증이 필요한 휴리스틱이다. 최대 8,000자를 취득하고 대조에는 최대 1,500자 발췌를 전달한다. 취득 본문의 해시·길이·잘림 정보를 발췌 전에 생성하고 서명에 포함해 동일성 집계에 사용한다.

## 무료 운영·보안

Groq `openai/gpt-oss-120b`를 유지한다. 과거 계정 한도 관측은 30 RPM, 1,000 RPD, 8,000 TPM, 200,000 TPD이며 현재 요금제·콘솔 한도와 별도로 확인해야 한다. 내부 모델 호출 예약 6,500토큰, 출력 최대 2,000토큰, 60초 예산 7,000토큰, 전역 동시 호출 1개, 타임아웃 60초, IP별 3회/분·20회/시간이다. 기본 일일 예산은 120,000토큰·최대 500요청이고 요청 상한은 실제 처리량 보장이 아니다. 확인한 현재 공급자 한도가 더 작으면 그 한도와 안전 비율을 따른다. 유료 제공자·자동 fallback·추론 재시도는 사용하지 않는다.

검색은 별도로 IP별 3회/분·20회/시간, 전역 하루 200회 안전 상한과 공급자 대기 상태를 사용한다. 이 값은 검색 업체의 공인 무료 한도가 아니다. 승인된 서비스의 실제 한도가 더 작으면 낮춰야 한다.

키는 서버 secret에만 둔다. D1에는 원문·검색어·분석 결과 없이 HMAC 호출자와 시각·예산·대기 상태만 저장한다. 조사 계획과 공개 발췌는 만료되는 서명 묶음으로 브라우저 메모리에 둔다. 사용자 작성 자료에 `web_fetched`를 붙일 수 없다. 로그에 원문·키를 출력하지 않는다.

## 검증과 남은 출시 조건

회귀 검사 통과는 정확도 검증이 아니다. [2026-11-02 품질 점검 기록](SESSION_SITE_QUALITY_2026-11-02.md)에는 당시 웹사이트 시험 332개, 타입 검사·빌드, 로컬 4개 화면 응답과 비활성 기본값 검증이 있다. 실제 브라우저에서 모의 조사 취소·재시작·입력 변경·늦은 응답, 직접 지정 명제의 조사→매체 좌표 연결, 내보내기 다운로드와 초기화, 팝업 키보드 조작·375px/560px 화면을 확인했다. 재현 스크립트는 [브라우저 검증 안내](../scripts/browser-qa/README.md)에 있다. 이는 합성 자료와 모의 응답을 사용한 범위다.

검색 후보 GDELT의 429는 과거 점검 기록이며 현재 안정성이나 무료 이용 조건의 확인을 대신하지 않는다. 외부 검색·취득은 무료 요금제·실제 잔여량·출처별 이용 조건·운영 승인과 실서비스 검증 전까지 비활성이다. 실제 기사별 본문·보일러플레이트·인코딩·발행일·인용 맥락과 모델 입장 분류의 정확도는 별도 검증해야 한다. 독립 평가자 2명의 40사례 라벨과 모델 비교, PCA/SVM 실측 성능, 공개 배포·운영 검증은 남아 있다.

2026-10-31 검증 기록: 회귀 172개 통과, 실제 무료 Groq 가상 기사 1건 성공(3,869토큰). 본문 논점 2개·사실/의견 주장 2개·본문 문장별 배정과 다른 관점 제안을 확인했다. 이는 독립 정확도 평가나 실제 기사 검색 검증이 아니다.
