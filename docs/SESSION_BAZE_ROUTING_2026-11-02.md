# BAZE 전환 검토와 실행 시 보호 적용

2026-11-02 KST. 사용자 요청: BAZE 95% 사용량 부근에서 ChatGPT 기본 사용량으로 자동 전환 가능한지 검토하고 구현한다.

## 확인과 결정

- Codex CLI 0.166.0의 도움말과 OpenAI 공식 인증·resume 문서를 확인했다. 현재 로컬 CLI는 ChatGPT 로그인 상태다. 인증 파일·키를 출력하거나 복사하지 않았으며 전역 Codex 설정을 변경하지 않았다.
- 현재 런처는 factchat을 강제하므로 이를 실행 시 정책 모듈로 교체했다. 최신 확인값 미등록 상태에서 새 정책은 ChatGPT를 선택한다. 예전 크레딧 스냅샷을 새 값으로 저장하지 않았다.
- 브라우저 접근 호스트가 연결되지 않아 BAZE 최신 사용량은 읽지 못했다. 공개 자료에서 지원되는 크레딧 계정 조회 API는 확인하지 못했다. 웹 내부 API나 인증 쿠키를 추출해 상시 조회를 만드는 방법은 적용하지 않았다.
- 가능한 범위는 실행 시점 선택이다. 최신 수동 확인 월간 크레딧이 95% 미만이면 BAZE, 95% 이상·확인 불가·만료·잘못된 기록이면 ChatGPT 인증 경로를 선택한다. 사용량 자동 조회·상시 감시·실행 중 교체는 미구현이다. 진행 중인 대화를 종료하지 않았다.

## 변경 파일과 역할

- 통합 담당: CLI-시작.cmd, BAZE-사용량-확인.cmd, scripts/codex-routing-policy.mjs, scripts/codex-routing.mjs, tests/codex-launcher.test.ts, 안내 문서와 AGENTS.md.
- 별도 감사 에이전트: 읽기 검토 및 tests/codex-routing.test.ts. 서로의 담당 파일을 동시에 수정하지 않았다.
- 정책 시험 중 잘못된 2월30일 확인시각이 Date.parse에서 보정되는 문제를 발견해 실제 달력 날짜 round-trip 검증을 추가했다.
- 모의 Windows 실행에서 -C의 공백·한글 경로 끝 백슬래시가 닫는 따옴표를 훼손하는 문제를 발견해 resolve로 경로를 정규화했다.
- 사용량 기록은 Git 제외 .sites-runtime/baze-monthly-usage.json에만 저장하며 숫자·단위·범위·확인시각·다음갱신일·수동입력 출처만 포함한다. 현재 실사용량 기록은 생성하지 않았다.

## 검증

- 최종 npm run check:record: 타입 검사·테스트314개·빌드 통과. 실제 API opt-in13개 제외. 로그: test-runs/2026-11-01T16-00-37-096Z/.
- 추가 정책/런처 시험42개 포함: 정확95%, 서로 다른 월간한도, 15분 유효기간, 미래시각, 한국시간 갱신일, 자정에 임의 충전하지 않음, 형식오류, 별도 공급자 명령과 세션 보존.
- 모의 Codex CLI로 Windows PowerShell 실행·한글/공백 작업경로·종료코드17 전달·ChatGPT 자식에서 API 키/사용자 URL 환경변수 제외를 검증했다. 이 시험은 실제 Codex 모델을 호출하지 않는다.
- node scripts/codex-routing.mjs auth-check: 실제 저장된 ChatGPT 로그인 확인. 실제 모델 권한/잔여량을 검증하는 추론 요청은 하지 않았다.
- npm run check:local 통과: 화면4곳 HTTP200, capabilities의 live/webSearch/webFetch false, 예시모드, 실시간 요청503, 로컬 설정 접근403. 로그는 위 최종 기록의 local-http.log.
- 이번 변경은 웹 UI를 수정하지 않았다. 새 시각 검증을 수행했다고 주장하지 않는다.

## 남은 범위

BAZE가 제공·승인하는 크레딧 조회 방식과 실제 계정 조건을 확인한 뒤 최신 사용량 수집을 연결해야 한다. 실제 ChatGPT 모델 호출·교차 공급자 대화 재개는 아직 검증하지 않았다. 실행 시 정책만으로 BAZE 장시간 세션이 95%를 초과하는 것을 막지는 못한다. 현재 열린 이 대화의 제공자를 변경하지 않았고, 자정5,000충전 조건도 검증하지 않았다. 웹사이트의 Groq 분석·무료 보호·검색 비활성은 유지했다.

전체 사용 안내와 공식 문서 근거는 BAZE_CODEX_ROUTING.md를 따른다. 검증한 변경은 GitHub 전용 브랜치에 커밋하며 원격 main은 보존한다.
