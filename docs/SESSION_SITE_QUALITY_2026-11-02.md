# Canva 메인 기능 연결과 조사·좌표 품질 점검

2026-11-02 로컬 개발 검증 기록이다. Canva `DAHZoL7I6ps`의 반원 게이지·편향·자극·신뢰·추천 카드·분석근거 버튼 배치를 유지하며 기능 연결과 경계 처리를 보완했다. 이번 후속 구현·통합은 Codex가 단독으로 수행했다.

## 반영한 동작

- 조사 결과를 수신할 때 현재 분석 ID에 연결해 메인 게이지, 조사 패널, 추천, 원문 표시, 좌표와 내보내기가 같은 자료를 사용한다. 다른 분석·미연결·모드가 다른 결과는 제외한다.
- 사용자가 입력한 **비교 명제**를 조사 계획·자료 취득·입장 대조에 전달한다. 직접 지정한 명제가 있으면 추출된 다른 의견보다 우선한다. 비교 명제를 원문 인용이나 사실 주장으로 만들지 않는다. 사실 주장이 없어도 명제에 대한 관점 탐색은 가능하다.
- 비교 명제 변경도 서명된 조사 입력의 변경으로 취급한다. 이전 계획·취득 자료로 변경된 명제를 조사할 수 없다. 명제의 검색 식별자는 실제 주장 ID와 겹치지 않는다. 사실 주장 최대 5개와 관점 1개라는 조사 범위를 유지한다.
- 취소·입력 변경·기능 비활성 시 후속 호출과 늦은 결과 반영을 막는다. 취소·실패·부분 완료·완료 뒤에는 새 조사 준비, 새 동의, 명시적 시작으로 재조사한다. 입력을 원상복구해도 자동 재호출하지 않는다.
- 동일 기사·명제에서 상충하는 관측 분류는 좌표 배치를 유보한다. www·추적 파라미터·해시 별칭을 추가 기사로 세지 않는다. 매체별 고유 기사 3개·적격 매체 2곳 기준과 차이 범위 0–2를 유지한다.
- 인용의 정수 위치·본문 경계·비공백·실제 일치를 검사한다. 시점 불명·불일치는 사실 상충 확정과 구분한다. 후속 실패·건너뜀은 이전 성공을 대신하며, 수치가 다른 자료를 반대 의견 기사로 바꾸지 않는다.
- 내보내기는 자연 문장 수와 중복 없는 최신 사실 대조를 집계한다. 실제 자동 조사 완료 수는 화면과 같은 외부 자료 기준을 사용한다. 새 분석과 초기화에서 원문·인용 포함 선택 및 피드백을 지운다. 기본 다운로드에는 원문·참고자료 본문·서명 토큰을 넣지 않는다.
- 입력창을 닫아도 진행 상태와 취소 버튼을 표시한다. 실시간 기능 비활성 상태에서 수정한 참고자료 대조를 요청하지 않고 설명한다. 한도 소진으로 예시에 전환해도 한도 안내를 유지한다.
- 근거 탭은 방향키·Home·End로 선택·포커스를 함께 이동한다. 팝업 원문 이동과 화면 크기 변경 뒤에도 제목과 닫기 버튼이 보이도록 대화상자 바깥 스크롤을 막고 내용 영역만 스크롤한다.

## 기사 문서 처리

`lib/server/article-document.ts`를 분리했다. BOM, HTTP charset, HTML 선언 순서로 해독하며 EUC-KR 등 선언된 한국어 인코딩을 지원한다. 깨진·지원하지 않는 인코딩을 임의의 UTF-8 본문으로 복구하지 않는다.

HTML은 article, main 순으로 본문 후보를 선택하고 메뉴·광고용 aside·스크립트·스타일·주석 등을 제외한다. 별개의 article 조각을 한 기사로 합치지 않는다. 제목·발행일·취득 본문 길이·잘림·추출 버전을 구분한다. 주석과 스크립트 문자열에 있는 가짜 charset·제목·날짜는 메타데이터로 사용하지 않는다. 본문 속 날짜나 수정일을 발행일로 추정하지 않는다.

이는 허용 출처용 제한된 휴리스틱이다. 의미 태그 없는 페이지의 대체 추출과 사이트별 DOM 차이는 별도 검증이 필요하다. 인용 문자열 일치는 해석 정확도나 기사 진실성을 보장하지 않는다. 기존 허용 호스트·리다이렉트 미추적·2 MiB 응답 제한·8,000자 취득 상한을 유지한다.
