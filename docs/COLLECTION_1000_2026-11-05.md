# 기사 1,000건 수집과 누적 검사

2026-11-05 기존 적격 후보 314건에 686건을 추가하여 **첫 기사 1,000건 수집과 누적 300·600·900·1,000건 검사를 완료**했다. 이후 사용자 요청으로 2,000건, 이어서 3,000건 수집을 진행한다. 자료 이용 승인·정치적 축 검증·생산 모델 적용은 완료하지 않았다.

## 후속 정제와 검사 이력

추가 수집 중 주택행정 시상·견본주택 개관 등 명백한 홍보성 기사를 발견해 전체 자료의 제목을 다시 검사했다. 초기 1,000건의 2건과 이후 수집본 4건, 총 6건을 활성 자료에서 제외하고 원문·사유는 로컬 검역 파일로 보존했다. 첫 300건에서 고정한 평가 153건은 이 제외 대상과 겹치지 않는다.

아래 표와 분포는 **초기 수집 당시 기록**이다. 초기 900·1,000건 보고서는 `docs/test-runs/2026-11-05-corpus-{900,1000}-initial/`에 보존했다. 기본 경로의 보고서는 정제한 자료로 다시 계산했다. 재계산 1,000건의 훈련 자료는 527건, 정확도 78.43%, Macro F1 0.7035이며 평가 자료는 같은 153건이다. 첫 1,000건 원본 스냅샷과 원래 SHA는 변경하지 않았다.

정제 후 1,000건은 초기 자료에서 홍보 2건을 제외하고 후속 자료 2건으로 채운 비교 구간이다. 원문은 `articles-reviewed-1000.local.jsonl`, 검사·지문은 기본 `1000/validation.json`에 있고, 초기 원본의 검증 기록은 `1000-initial/validation.json`에 있다. 후속 수집·정제 결과는 [2,000건 작업 기록](COLLECTION_2000_2026-11-05.md)을 따른다.

## 수집과 집계 기준

- 기간: 2024-01-01부터 2026-11-04까지. 기존 실험 기간을 유지한다.
- 매체 후보: 프레시안·오마이뉴스·데일리안·뉴데일리, 각 250건을 목표로 한다. 뉴데일리 본지와 경제판은 모델 평가에서 구분한다.
- 주제: 의대 정원, 국민연금 개혁, 최저임금, 전기요금, 주택 공급, 원전 정책.
- 실제 본문 300자 이상, 유효한 발행일, 주제 관련성을 확인한 자료만 집계한다. URL 별칭과 정규화한 본문 해시의 중복은 제외한다.
- 공개 수집 정책을 확인하고 요청 간격을 유지한다. 로그인·유료벽·접근 거부를 우회하지 않으며 401·403·429 응답을 받으면 해당 호스트 수집을 멈춘다.
- 공개 접근 가능 여부와 학습·모델 배포 권한은 별개다. 이용 상태와 원본 독립성은 검토 대기다.
- 원문·원본 HTML·실험 가중치·검토표는 무시되는 로컬 `.sites-runtime/collection-1000-20261105`에 보관한다. 공개 저장소에는 코드와 집계 결과만 포함한다.

## 중간 검사

기존 120건과 별도 확장본 204건을 합쳐 324건을 확인했다. 날짜·본문 길이·주제 관련성 등의 기준으로 10건을 보류하여 재개 시점의 집계는 314건이다.

첫 300건에서 평가 기사 153건과 평가 주제를 고정했다. 이후 검사에서도 같은 평가 기사로 비교한다. 평가 주제의 나머지 기사와 평가 자료에 근접 중복되는 훈련 자료는 훈련에 넣지 않는다. 문자 TF-IDF는 훈련 자료에서만 적합한다. 재사용하는 평가 자료이므로 최종 독립 평가와 구분한다.

| 누적 고유 기사 | 고정 평가 | 훈련 기사 | 매체명 제거 정확도 | Macro F1 | 훈련 다수 매체 기준 정확도 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 300 | 153 | 147 | 67.97% | 0.5007 | 44.44% |
| 600 | 153 | 328 | 71.90% | 0.5841 | 44.44% |
| 900 | 153 | 485 | 79.08% | 0.7304 | 9.15% |
| 1,000 | 153 | 526 | 79.08% | 0.7071 | 9.80% |

마지막 열은 각 시점의 **훈련 자료에서 가장 많은 매체만 예측**했을 때의 기준값이다. 훈련 자료의 매체 구성에 따라 예측 매체가 달라질 수 있다. 고정 평가 자료에서 가장 많은 클래스의 비중은 계속 44.44%이며, 평가 자료의 매체별 수량 차이는 Macro F1과 함께 확인한다.

300건에서 근접 중복 후보는 0쌍이다. 날짜 시간대 검토 107건, 경제판 범위 검토 23건, 꼬리 문구 검토 14건이 남아 있다. 매체별 수량 차이와 표본 구성의 영향을 함께 확인해야 한다.

600건에서도 근접 중복 후보는 0쌍이다. 추가 자료 중 2건은 기존 의대 정원 핵심어 검사에서 주제 검토 대상으로 표시되어 모델 실험에서 보류했다. 실제 기사를 취득한 건수와 모델 검사에 사용할 수 있는 건수는 구분한다. 날짜 시간대 검토 158건, 경제판 범위 검토 23건, 꼬리 문구 후보 117건이 남아 있다.

900건에서 1,000건으로 늘렸을 때 정확도는 유지됐고 Macro F1은 하락했다. 자료량 증가가 모든 매체의 분류 성능 개선으로 이어지지는 않았다. 같은 평가 기사를 사용했으나 최종 독립 평가나 정치적 편향 정확도를 입증하는 결과는 아니다.

- 뉴데일리는 본지 140건·경제판 110건이다. 분류 실험은 별도 클래스로 취급한다.
- 전기요금 자료가 상대적으로 적다. 본문·기간 기준을 낮추지 않고 다른 정책 주제를 조금 더 확보해 각 매체 250건을 채웠다. 주제별 완전 균등 표본은 아니다.
- 실제 본문 1,000건·정규화 본문 해시 1,000개, 동일 본문 중복 0건, 코사인 유사도 0.92 이상 근접 중복 후보 0쌍이다. 독립 보도라는 사람 검토를 대신하지 않는다.
- 날짜 누락 0건, 최소 본문 348자·최대 13,866자다. 매체명 제거 후 빈 본문·100자 미만 본문·절반 이상 제거된 본문은 모두 0건이다.
- 주제 핵심어 재검토 3건은 모델 실험에서 보류했다. 시간대 검토 250건, 경제판 범위 검토 110건, 꼬리 문구 후보 161건이 남아 있다.
- 첫 1,000건 원문은 `articles-first-1000.local.jsonl`, 로컬 무결성·분포 기록은 `dataset-manifest.local.json`, 각 중간 결과는 `checkpoint-{300,600,900,1000}`에 있다. 이후 누적 2,000건 수집은 `articles.local.jsonl`에 추가하며 첫 1,000건 스냅샷은 보존한다.
- 원문 파일 SHA-256: `a9cb79e83a0078d68aedd58fc018411cd3162f459bfc6291cf15d3cb38ce6db0`.
- 코드 검증: 타입 검사·프로젝트 자동 검사·제품 빌드 통과, Python 연구 검사 58개 통과. 실제 모델 API opt-in 검사는 제외했다. Python 3.14.3, scikit-learn 1.9.0에서 측정했다.

공개 집계와 검사 기록은 `docs/test-runs/2026-11-05-corpus-{300,600,900,1000}/`에 있다. 최종 `validation.json`은 본문 없이 분포·검사·파일 지문만 기록한다.

정확도와 F1은 **발행 매체 분류**의 실험 지표다. 정치적 편향 판단의 정확도나 사실 여부를 뜻하지 않는다. 수집량이 목표에 도달해도 두 독립 평가자의 축 검토, 이용 조건, 원본 독립성 확인을 대신하지 않는다. 생산용 `lib/data/bias-model.json`은 이 작업으로 변경하지 않는다.

## 재현

```powershell
python research/checkpoint_bias_collection.py --base .sites-runtime/collection-1000-20261105
```

도달한 누적 검사만 실행하며, 동일 입력의 완료 결과는 재사용한다. 다른 입력으로 기존 검사 결과를 덮어쓰지 않는다. 기존 topic-heldout 진단도 별도 저장하지만 평가 표본이 바뀌므로 학습 곡선 비교에는 고정 평가 결과를 사용한다.
