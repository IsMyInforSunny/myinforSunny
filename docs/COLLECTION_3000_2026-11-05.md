# 누적 3,000건 기사 수집

사용자는 누적 2,000건 완료 후 3,000건까지 계속 진행하도록 요청했다. 2,000건 정제·고정 평가 검사와 저장을 마친 뒤 1,000건을 추가한다. 이 문서는 3,000건 단계의 진행 기록이며 아직 완료 기록이 아니다.

- 기존 4개 매체 후보에서 각 750건을 목표로 한다. 뉴데일리 본지와 경제판은 분류에서 구분한다.
- 기존 6개 정책 주제, KST 기준 2024-01-01~2026-11-04, 본문 300자·유효 날짜·중복 제외·명백한 홍보 자료 제외 조건을 유지한다.
- 매체·주제 누적 165건 상한으로 희소 주제와 다른 주제의 표본 수 차이를 관리한다. 주제별 균등 표본은 아니다.
- 누적 2,100·2,400·2,700·3,000건에서 같은 평가 기사 153건으로 검사한다. 자료량에 따라 성능이 떨어져도 평가 표본이나 설정을 바꿔 개선으로 보고하지 않는다.
- 수집 접근 제한과 요청 간격을 유지한다. 원문·HTML·실험 가중치는 로컬에 보관하고 집계와 코드만 공개 저장소에 저장한다.
- 이용 조건·원본 독립성·정치적 축에 대한 검토와 생산 모델 적용은 이 수집량 목표와 별개다.
