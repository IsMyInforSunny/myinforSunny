# 편향·신뢰 방법 작업 기록 · 2026-11-02

- **신뢰:** 사용자가 “MDC”는 MBC라고 확인했다. Reuters Institute Digital News Report 2025 한국 매체별 표의 14개 매체 Trust 응답을 100으로 나눈 보조 가중치로 등록했다. MBC는 0.61이다. 같은 조사표의 신뢰하지 않음 응답은 해석 맥락으로 문서화하고 중복 가중하지 않았다. 실제 기사에 대해서는 웹 취득, 정확한 인용 위치, 발행 시점, 서로 독립된 원본, 주장별 뒷받침·상충·충돌 결과를 함께 사용한다. 매체별 정정률·사실 정확도는 비교 가능한 분모가 없어 아직 점수에 넣지 않았다.
- **편향:** 매체별 기사 모델 좌표의 중심을 동일한 비중으로 평균해 상대 중간지점을 만든다. Claude가 기록한 좌익 4곳·우익 3곳 분류는 축 부호와 분리 검증에만 사용한다. 동일 원문 그룹은 학습·평가 양쪽에 들어가지 않는다. 검증된 기사 좌표와 모델이 없어 반원 게이지는 계산 대기다.
- **UI:** 메인 신뢰 설명과 방법론에 위 기준을 연결했다. 반원 게이지는 편향 강도를 나타내며, 가상 예시는 실제 조사로 표시하지 않는다.
- **검증:** 로컬 타입 검사·빌드 통과, 전체 테스트 412개 통과·실제 API 선택 검사 13건 건너뜀. GitHub 업로드 브랜치에서도 타입 검사·빌드 통과, 전체 테스트 452개 통과·실제 API 선택 검사 13건 건너뜀. 로컬 브라우저에서 메인 설명과 방법론을 확인했고, 방법론은 375px 화면에서 가로 넘침 없이 표시됐다.
- **남은 일:** 이용 가능한 실제 매체 기사 표본과 SVM 학습·독립 평가가 필요하다. 자동 조사와 외부 기사 검색은 이용 조건·비용·실서비스 검증을 마친 뒤 활성화한다. 신뢰 가중치가 없는 매체가 대조에 포함되면 해당 주장 결과를 보류한다.
