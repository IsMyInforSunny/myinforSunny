## 사용자 요구와 현재 구현

1. 매체별 기사 입장을 좌표에 올리는 흐름은 `articleMapPoints` → `publisherPositions` → `MediaPositionMap`으로 분리되어 있다.
2. 같은 명제에 대한 반대 -1, 맥락 보충 0, 찬성 +1 관측값을 매체별로 평균낸다. 고유 기사 3개 이상인 매체만 좌표가 생기고 적격 매체 2곳 이상이면 매체별 동일 가중 평균을 잠정 기준선으로 쓴다.
3. 입력 기사와 기준선의 비교는 `|입력 기사 입장 - 잠정 기준선|`, 범위 0~2다. 현재 입력 기사 입장은 **사용자가 직접 지정**한다. 따라서 자동 입장 분류와 자동 편향 판정이 완성됐다고 말할 수 없다.
4. 가로축은 해당 명제에 대한 입장, 세로축은 고유 기사 수다. 언론사에 고정된 정치 성향이나 객관적 편향 점수를 부여하지 않는다. 0도 중립 인증이 아니다.
5. 실데이터는 현재 분석 ID·모드가 일치하고, 웹에서 취득한 본문에 해당 명제의 입장 인용이 정확히 존재해야 들어온다. 외부 검색/본문 취득이 꺼져 있으면 실제 매체 좌표는 계산 대기다. 가상 체험은 별도 선택이며 실제 자료와 섞지 않는다.

## 별도 보완 후보

`MediaPositionMap`은 여러 검토 결과를 개별 `articleMapPoints` 호출로 풀어 결과 간 URL 분류 충돌을 보존한다. 그러나 **하나의 검토 결과 안**에 같은 URL의 서로 다른 참조/분류가 반복되면 `articleMapPoints` 내부 URL Map이 마지막 관측을 덮어쓸 수 있다. 이 경로는 이번 제한된 변경에서 고치지 않았다. 공개 데이터 경로에서 발생 가능한지와 입장 중복 검증 정책을 함께 검토해야 한다.

API 키 열람, 외부 기사 수집, 실제 모델 호출, 설치, 공개 배포는 하지 않았다.
