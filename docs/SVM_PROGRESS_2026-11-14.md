# 문장 SVM 구현 및 검증 상태 — 2026-11-14

실제 기사에서 쟁점·방향·발화자를 분류하는 의미 벡터 + 계층형 선형 SVM 후보를 구현했다. 성능 기준을 통과한 후보는 있지만, 기사 이용 검토와 Browser 화면 검증이 완료되지 않아 운영 모델은 비활성 상태다. 공개 배포하지 않았다.

## 모델과 검증 범위

- 기존 3,000건 중 원전 관련 547건·12,565문장을 로컬에서 준비했다. 새 기사 수집 건수로 계산하지 않는다.
- AI 검토 라벨은 46개 기사에 있다. 의미 벡터 실험은 학습 218문장, 고정 평가 149문장, 별도 반대 방향 도전 20문장을 사용한다. 중복 문장 하나를 공유하므로 고유 벡터는 386개다.
- 평가 기사와 도전 문장의 기사·사건 그룹 겹침을 제외한다. 기존 외부 평가 분할을 유지한다. 사람이 평가한 정확도 표본은 0건이다.
- 원전 관련 세부 쟁점만 지원한다. 일반 뉴스 전체에 대한 성능이나 좌우 이념 판별을 입증하지 않는다.

후보 `be2b3b35dd956060b43ebb30`의 입력 준비·학습·평가를 보관된 실제 벡터로 재실행해 후보와 보고서의 완전 일치를 확인했다. 이 재현에는 API 호출이 없다. 원본, 라벨, 벡터, 실험 보고서는 `.sites-runtime/svm-improvement-20261114/`에 보존하며 Git에 포함하지 않는다.

## 연결한 기능

1. 문장을 의미 벡터로 바꾼 뒤 방향 유무 → 찬반 방향, 발화자, 쟁점을 각각 선형 SVM으로 분류한다. 낮은 마진은 유보한다. 광고·해시태그·저작권 표시 문장은 집계에서 제외한다.
2. URL 본문 분석과 검색·직접 취득한 관련 기사에 같은 서버 모델 경로를 연결했다. 유효한 운영 모델만 불러오며 실패하면 편향 분석 미완료로 표시한다.
3. 원문 URL·발행일·본문 해시를 서버 서명 토큰으로 묶는다. 비교 기사와 사건 유사성 및 3일 기간을 확인하고, 학습 원본과 중복을 제외한다.
4. 같은 사건·쟁점에서 매체별 고유 기사 3건 이상, 매체 2곳 이상이라는 기존 기준을 유지한다. 표본이 부족하면 상대 점수와 반대쪽 추천은 대기로 남는다.
5. 의미 벡터 캐시와 요청 병합, 실제 사용량 기록, 429 중단, 취소 전파를 구현했다. 자료 취득도 모델을 쓰면 계획·취득·비교에 최소 20.1초 간격을 적용해 기존 분당 3회 요청 제한을 유지한다. 시간당 20회 제한도 유지한다. 따라서 전체 조사가 항상 30초 안에 끝난다고 보장하지 않는다.

실험용 벡터 추출은 기존 NVIDIA 환경변수를 사용해 14회 호출했다. 공급자 보고 사용량은 20,579토큰, 보수적 예약 사용량은 91,000토큰이며 기존 로컬 예산 장부를 보존한다. 유료 API나 자동 재시도·다른 모델 fallback은 추가하지 않았다.

## 비교 기사 표본 추가 진단

`scripts/check-live-voice-population.mjs`로 실제 보관 기사 전체에 현재 서비스의 사건 유사도·발행일 규칙을 적용했다. 학습 원본 해시 38개를 제외하고 본문 해시로 중복 제거한 유효 기사 509건에서 사건 조건을 만족하는 쌍은 6쌍이었다. 각 입력을 포함하는 총 3일 기간 안에서 매체별 3건 이상·2개 매체 이상인 비교 집합을 만들 수 있는 입력은 **0건**이었다.

이는 SVM 쟁점 일치·방향 문장 수·미확정 문장·실제 취득 이력 조건을 적용하기 전의 표본 상한이다. 추천 정확도 평가가 아니다. 따라서 현재 보관 기사 수만 늘어났다는 이유로 반대 관점 추천이 가능하다고 판단하면 안 된다. 동일 사건별로 여러 매체의 독립 기사 원문을 확보하는 수집 경로가 추가로 필요하다. 이 진단은 원문을 업로드하거나 API를 호출하지 않으며 상세 기사별 결과는 로컬 runtime에만 보존한다.

## 검색 후보 반복 결함 수정

로컬 기사 검색이 결과 수·매체별 수 제한을 적용한 다음 이미 취득한 URL을 제외하고 있었다. 그 결과 같은 검색어로 이어서 조사할 때 앞쪽 후보만 반복되고, 뒤에 있는 독립 기사에 도달하지 못할 수 있었다. 이미 취득한 URL을 먼저 정규화해 제외한 뒤 순위·개수 제한을 적용하도록 수정했다. 추적 파라미터·동일 매체 호스트 변형은 같은 주소로 처리한다. 모든 로컬 후보가 소진되면 기존 설정된 검색 경로로 넘어가며, 이용 미승인 후보는 계속 제외한다.

추가 회귀 검사와 전체 테스트 978개가 통과했다(13개 건너뜀). 타입 검사와 빌드도 통과했다. 현재 보관 인덱스는 이용 미승인 상태라 이 수정만으로 현 서비스의 기사 추천이 가능해졌다는 의미는 아니다. Browser 연결 목록은 계속 비어 있어 화면 검증은 미완료다.

## 실제 URL 서버 검사 및 취득 수정

실제 기사 [한수원, 원전 건설 과정서 국민 목소리 청취](https://www.dailian.co.kr/news/view/1667349/)를 빌드된 로컬 서버 `/api/analyze`에 입력했다. 화면 조작 도구가 없어 서버 요청으로 실행했으며 UI 검사로 계산하지 않는다.

- 수정 전: 1.47초 후 HTTP 422 `ARTICLE_BODY_UNAVAILABLE`. 기사 주소가 같은 출처의 제목 포함 주소로 301 이동했으나 취득 코드가 모든 이동을 거부했다.
- 수정: 원래 HTTPS origin 안에서 정확한 허용 목록을 만족하는 이동만 최대 두 번 수동 처리한다. 교차 출처, HTTP, 사용자정보 포함 주소, 반복 이동은 차단한다. 최종 URL을 원문으로 기록한다. 공통 5초 취득 제한과 각 응답의 noai/nosnippet 중단을 유지한다.
- 수정 후: 캐시 miss, HTTP 200 `success`, 전체 15.47초. 원문 839자 전체, 주장 5개, 표현 분석 18개가 반환됐다. AI 응답 완료는 약 12.53초였다.
- 화면과 같은 점수 계산 함수 결과: 자극 표현 0/18 = 0점, 근거 출처 명시 1/5 = 20점. 편향은 운영 SVM 비활성으로 대기, 출처 가중 근거 점수는 외부 자료 대조 전이라 대기다. 출처 명시 점수를 신뢰 점수로 대신 표시하지 않는다.

의미 벡터 제공자 요청도 workerd에서 지원하지 않는 `redirect:error`를 `manual`로 바꾸고 모든 이동 응답을 명시적으로 거부했다. 잘못된 벡터 행은 구조화된 오류로 처리한다. 이것은 공급자 경계 테스트로 검증했으며 활성 SVM의 실제 API 실행 증거는 아니다.

관련 테스트 추가 후 전체 986개 통과(13개 건너뜀), 타입 검사·빌드 통과. 실제 API 호출·응답 상세는 로컬 runtime에만 보존한다. Browser 미연결, 데이터 이용 검토, 비교 표본 확보는 여전히 미완료다.
