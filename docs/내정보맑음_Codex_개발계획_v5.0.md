# 개발계획 v5.0

기준: 2026-10-31. 목표는 기사 입력에서 본문 분석·자동 신뢰성 조사·다른 관점·실제 관련 기사까지 이어지는 무료 웹사이트다. 수동 자료 대조로 목표를 축소하지 않는다.

## 역할과 완료한 작업

Claude는 문장 구간·소수점/날짜/인용 처리, 본문 문장별 논점 배정, 논점 컴포넌트, 관련 회귀 검사를 구현했다. 별도 읽기 전용 검토 후 500자 경계·국기 이모지·공백 분할도 수정했다. Claude는 명령·테스트·네트워크·배포를 수행하지 않았다.

Codex는 통합과 검증을 맡는다. 자연 문장별 표현 집계, 재대조 결과 일관성, 반복 인용 위치 보존, 자동 조사 서명·API·실행 단계·진행 UI·검색 상한·D1 마이그레이션을 구현했다. 동일 파일을 동시에 수정하지 않고 Claude의 완료 출력을 확인한 뒤 통합한다.

## 다음 작업 순서

1. 타입·전체 회귀·빌드 검사 및 공개 사이트 본문 분포·세 페이지·모바일 점검. 새 Groq 분석 출력과 토큰 예산은 가상 공개 입력으로 실제 확인한다.
2. 무료 검색 공급자 결정. 공식 이용 조건·무료 범위·가입 자격·AI 대조 사용 가능 여부·실제 응답을 확인한다. 기존 사용자 지시에 따라 결과를 보고하고 검색 서비스 연결 승인을 받은 뒤 활성화한다. 현재 GDELT 429를 해결하지 않은 상태에서 정상이라고 발표하지 않는다.
3. 허용 출처의 본문 추출 개선. 본문 영역·한글 인코딩·반복 메뉴·날짜·짧은 발췌 정확도·호스트별 접근 조건·실패 상태를 검사한다.
4. 실제 기사 조사 통합 검증. 주장별 검색→취득→대조→신뢰성 집계와 다른 관점의 출처·관련 기사 추천을 확인한다. 인용 일치는 해석 정확성을 보장하지 않는다. 검색 실패·429·타임아웃·취소·날짜 불일치·본문 없음·서명 위조·입력 변경을 확인한다.
5. 의견만 있는 글도 다른 관점의 기사 탐색이 가능하게 한다. 현재 사실 주장 중심 실행기를 의견 탐색까지 확장한다. 사실 수치가 다른 기사와 반대 입장 기사는 구분한다.
6. 조사 결과 내보내기·모바일 진행 UI·한도 소진 예시 전환을 완성한다. 실제 동작을 확인한 뒤 문서와 활동계획서의 구현 상태를 맞춘다.
7. 독립 평가자 2명이 가상 40건을 라벨링하고 실제 LLM 결과와 비교한다. 사람 라벨·실측 없이 정확도를 게시하지 않는다. PCA·SVM은 별도 연구·비교 범위를 명시한다.

## 검수 원칙

정치·개인 성향 분류 없이 학교생활 같은 비정치적 예시를 사용한다. 개인정보·비공개 대화는 받지 않는다. 퍼센트는 분모가 보이는 집계이며 진실 확률이 아니다. 키·원문을 로그나 Git에 남기지 않는다. 유료 전환과 예산 증액은 실행하지 않는다.

회귀 통과·타입 통과·빌드 성공·공개 배포 성공·실서비스 검증·사람 정확도 평가는 서로 다른 완료 상태로 보고한다.
