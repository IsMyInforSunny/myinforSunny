# 실기사 분석과 응답 지연 점검 · 2026-11-12

## 확인한 흐름

- production 빌드 페이지를 로컬 브라우저에서 열어 한겨레 과학 기사 `https://www.hani.co.kr/arti/science/science_general/1286549.html`를 링크로 제출했다.
- 일반 로컬 서버는 기본값이 Groq/실시간 분석 비활성 상태여서, 프로젝트가 제공하는 `start:nvidia` 로컬 실행 명령으로 다시 열었다. NVIDIA DeepSeek 전송 동의 후 분석했다.
- 기사는 2,722자로 취득됐고, 화면에는 65문장 분석이 표시됐다.
- 자극 표현 1/65문장(표시값 2%), 공격 표현 0문장, 명시 출처가 연결된 사실 주장 2/5개(40%)가 나왔다. 결과는 일부 항목 미판정 상태였다.
- 편향 방향은 본문 명제에 대한 질적 방향만 표시됐다. 동일 논점 SVM 기준선은 검증 통과 전이라 편향 강도 점수를 내지 않았다.
- 관련 기사는 표시되지 않았다. 보유한 3,000개 색인 전체가 이용 승인 미완료 상태여서 추천에서 제외된다.

## 측정된 지연

Worker 기록 기준:

| 구간 | 시간 |
| --- | ---: |
| 기사 원문 취득 | 1.1초 |
| NVIDIA 응답 헤더까지 | 209.8초 |
| 첫 생성 토큰까지 | 210.3초 |
| 첫 토큰부터 완성된 응답까지 | 194.2초 |
| 전체 분석 API 요청 | 405.8초 |

원문 취득과 사이트 후처리는 약 2초였다. 약 404초가 모델 API 호출에 들었다. 특히 첫 토큰까지 약 3분 30초를 기다렸고, 생성 스트림이 완성되기까지 약 3분 14초가 더 걸렸다. 따라서 주된 원인은 브라우저 렌더링이나 기사 취득이 아니라 NVIDIA 호스팅 DeepSeek 모델의 대기·생성 지연이다. 요청에는 이미 `reasoning_effort: "none"`을 넣었지만 이 측정에서는 충분히 빨라지지 않았다.

현재 연결은 **NVIDIA API를 통해 DeepSeek V4.1 Flash를 호출**한다. DeepSeek 공식 API에 직접 연결한 구성과는 다르며, 현재 환경에는 NVIDIA 키만 확인됐다.

## 이번 수정과 확인

- 색인 API의 빈 결과가 “검색어 후보가 없음”으로만 보이지 않도록, 이용 승인 미완료 기사라 추천을 보류했다는 이유를 응답과 화면에 표시했다.
- 만료·호스트·키워드 검사를 통과해도 사용 승인되지 않은 기사는 후보에서 빠지는 기존 필터를 유지했다.
- `npm run typecheck`, 전체 Vitest, production build를 통과했다. Vitest 결과는 888 passed, 13 skipped다.
- 변경 코드는 로컬에서만 확인했다. 공개 사이트에는 배포하지 않았다.

## 지연을 줄일 수 있는 경로

1. NVIDIA 응답의 대기와 생성 시간을 계속 분리 측정한다. 첫 바이트·첫 콘텐츠·완료 시간을 이미 서버 로그에 남긴다.
2. 분석 스키마와 지시문을 줄이고 출력 상한을 둬 생성량을 검증하되, 문장 누락이나 잘못된 완성 결과를 정상 처리하지 않는다. 상한은 이번 응답의 사용 토큰 수를 확인한 뒤 정해야 한다.
3. 같은 사용자·같은 URL의 성공 분석은 현재 10분 캐시를 사용한다. 현재 실기사 결과는 일부 항목이 미판정이라 성공 캐시에 들어가지 않는다.
4. 공식 DeepSeek API 어댑터를 추가했고 모의 API 응답으로 계약을 검증했다. 첫 토큰 대기 개선 여부는 실제 공식 키로 같은 기사를 보내 비교해야 한다. 공식 API 키가 이 환경에 설정돼 있지 않아 이번 작업에서 전환 효과를 검증하지 않았다.

## 기능상 남은 제한

- 기사 입장·본문 위치 표시와 편향 강도는 다른 기능이다. 검증되지 않은 좌우 위치·SVM 점수를 만들어 표시하지 않는다.
- 기사 색인은 3,000건이 있어도 이용 승인 검토가 끝나지 않으면 추천할 수 없다. 이 상태가 해결되기 전에는 “다른 논점 기사 추천 완료”라고 할 수 없다.
- 이번 실제 응답은 부분 분석이었다. 표시된 40%는 분석기가 추출한 사실 주장 5개 안에서 출처 표기가 있는 비율이며 기사 전체 사실 주장의 완전한 비율로 해석할 수 없다.
