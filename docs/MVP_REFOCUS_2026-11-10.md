# 핵심 MVP 복귀 계획 · 2026-11-10

사용자 결정(2026-11-10): 정치 매체 편향 연구를 계속 확장하지 않고, 활동계획서 v4.1의 핵심 서비스로 돌아간다.

## 왜 바꾸는가

- 활동계획서 v4.1은 "청소년이 기사·댓글의 표현·논점·근거를 스스로 살펴보는 성분표"이며 시연은 가상 학교생활 자료, 정치 성향 분류 없음이다.
- 11-04~11-05 작업 대부분은 4개 매체 정책 기사 3,000건 수집과 매체 분류 SVM 실험이었다. 이 실험의 지표는 발행 매체 식별(3,000건 66.01%, 2,400건 75.16%)이며 편향 정확도가 아니다. `lib/data/bias-model.json`은 `null`이다.
- 실제 기사 전체 분석은 NVIDIA 로컬 실행에서 502/504로 끝나 성공이 확인되지 않았다. 공개 사이트는 Groq 기본값이다.
- 그 결과 화면의 세 점수가 대부분 `산출 대기`로 보일 위험이 크다.

## MVP 범위 (완성 대상)

1. 기사 링크 또는 본문·댓글 입력
2. 문장별 밑줄·이유·원문 인용 (논점·표현·사실/의견 주장)
3. 자극 점수: 검출 문장 / 전체 문장 ×100, 분모 표시
4. 신뢰: 근거 출처 명시 점수를 기본 숫자로 표시 (AGENTS.md 2026-11-03 규칙). Reuters 가중·외부 대조는 보조 정보
5. 사용자가 고른 주장과 참고자료 수동 대조
6. 다른 관점 제안(출처 없음 표시)·JSON 내보내기·작은 팝업
7. 가상 학교생활 예시 7종이 키 없이 동작

## 동결 (이번 범위에서 하지 않음)

- 신규 기사 수집, 신규 매체 추가(Claude 신규 매체 배치 `claude-new-publishers-20261105/`는 수집 전 단계에서 중단)
- 매체 분류 SVM 튜닝·학습 확대. 3,000건 자료와 결과는 보존하고 "매체 문체 분류 실험(편향 측정 아님)" 부록 연구로만 서술
- NVIDIA DeepSeek 기본 전환. 로컬 실험으로만 유지
- Firecrawl 인증·유료 검색

편향 게이지는 3축 UI를 유지하되 "비교 모델 연구 단계" 설명을 보여 준다. 게이지를 숨길지는 사용자 결정이다.
