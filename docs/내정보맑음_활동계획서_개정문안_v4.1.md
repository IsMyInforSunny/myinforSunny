# 내 정보 맑음? — 활동계획서 개정 문안 v4.1

2026-10-30. 원본 대회 양식 PDF를 덮어쓰지 않은 제출용 교체 문안입니다. 구현 상태를 3개 개발 문서 v4.1과 맞췄습니다.

## 문제와 목표
청소년이 기사와 댓글의 표현·논점·근거를 스스로 살펴볼 수 있도록 웹 기반 정보 성분표를 제공합니다. AI는 게시를 막거나 정답을 정하지 않고 인용과 분석을 제안합니다. 시연은 가상 학교생활 자료로 구성하며 개인정보·비공개 대화·정치 성향 분류를 받지 않습니다.

## 활용 기술 표
| 기술 | 역할 |
|---|---|
| 사전학습 무료 LLM(Groq) | 논점·표현·주장과 원문 인용 후보 추출, 다른 관점 제안 |
| 인용·참조 검증 | 원문과 참고자료의 start/end 및 인용 일치 검사 |
| 서버 집계 | 논점 분포·자극성·근거 충분성의 건수와 분모 표시 |
| 웹 UI·서버 API | 본문 붙여넣기, 결과·근거 확인, 자료 대조, 무료 한도 보호 |
| 임베딩+PCA / SVM | 선택 탐색·소규모 라벨 비교 연구. 완료 전 구현 성과로 쓰지 않음 |

Moderation API의 사전 검수·필터링과 자동 게시 차단은 사용 기술 표에서 삭제합니다.

## Ⅳ-1 서비스 동작 교체 문안
사용자가 공개·가상 기사의 본문과 댓글을 웹사이트에 붙여 넣으면 논점 분포 / 자극성 / 근거 충분성을 한 화면에서 보여 줍니다. 분모가 보이는 건수와 원문 인용을 먼저 표시합니다. 작은 표본에는 퍼센트를 표시하지 않으며, 자료가 없으면 미대조로 남깁니다. 사용자가 선택한 주장과 참고자료를 대조해 출처에서 확인됨·입력한 출처와 다름·불충분 등을 설명합니다. 다른 관점은 AI 제안·출처 없음으로 구분합니다. 기사 검색은 현재 승인·연결 검증 전 단계이며 추후 기능입니다.

구조도 라벨: 텍스트 입력 → LLM 추출 → 인용·참조 검증 → 분모 있는 집계 → 3축 성분표 → 선택 주장·입력 자료 대조 → 사용자 판단.

브라우저 확장·읽는 페이지 자동 감지는 발전 계획으로 옮깁니다. 피드백은 검토 기록 내보내기이며 자동 재학습을 하지 않습니다.

## 컨셉 화면 교체 기준
자극성 90%, 편향 34/66, 공격성 56% 등 검증되지 않은 점수 이미지는 제출본에서 제외합니다. 새 화면에는 논점 3개 / 검토 표현 1문장 / 사실 주장 0개·해당 없음처럼 가상 예시의 실제 집계를 씁니다. 가상 예시·조사 아님을 표시합니다. 최종 제출에는 배포 화면의 검증된 캡처를 사용합니다.

## 평가와 성과 표현
기존 6종에 출처 확인 예시 1종을 추가하고, 원문·자료 인용 일치와 자료 없는 수치 주장을 회귀 검사합니다. 별도 학교생활 가상 자료 40개와 사람 2명의 빈 라벨 양식을 준비했습니다. 실제 라벨·모델 비교 전에는 정확도 수치를 쓰지 않습니다. 실제 Groq 시험은 연결·형식 선별 시험이며 독립 성능 평가가 아닙니다. 사람 평가와 관련 기사 검색은 미완료 항목으로 공개합니다.
