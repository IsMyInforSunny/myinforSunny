# 내 정보 맑음? — 개발계획 v4.0

2026-10-30 · **현재 개발 기준**. 기술명세 v4.0·아키텍처 v4.0과 함께 적용합니다. v1~v3의 상충하는 기술 선택·단계 정의를 대체합니다. 이번 개정은 설계 문서 수정이며 Groq 연결이나 실제 모델 평가가 완료됐다는 뜻은 아닙니다.

## 1. 확정한 방향

본문·댓글을 붙여 넣으면 **논점 분포 / 자극성 / 근거 충분성**을 한 화면의 3축 성분표로 보여 주는 웹 MVP를 만듭니다. AI는 분석과 검토 자료를 제공하며 글을 삭제하거나 게시를 막지 않습니다. 정치 성향·개인·집단의 성격을 분류하지 않습니다.
멘토링 PPT의 사전학습 LLM·임베딩 활용, PCA 탐색, 라벨이 있을 때의 SVM, 외부 평가를 유지합니다. 언어모델이나 여러 과제별 분류기를 직접 학습하는 것은 필수 경로에서 제외합니다. 팀이 구현하는 핵심은 과제 정의·인용 검증·분모가 있는 집계·오류 처리·사람 평가입니다.

최종 주 흐름: **공개·가상 텍스트 입력 → 무료 LLM의 논점·표현·주장·인용 추출 → 원문 일치·참조 검증 → 3축 성분표 → 사용자가 고른 주장과 입력 자료 대조**.
임베딩·PCA·SVM은 이 흐름 옆의 선택 실험입니다. PCA를 거쳐야만 기본 분석이 가능하도록 만들지 않습니다.

## 2. 서비스 선택과 확정 조건

**1순위 후보는 Groq Free**이며 `openai/gpt-oss-120b`와 `qwen/qwen3.8-27b`를 한국어 샘플로 비교한 뒤 하나만 기본 모델로 고정합니다. 이 모델명은 Groq에서 호출하는 공개 모델 ID이며 OpenAI 유료 API를 호출한다는 뜻이 아닙니다. API 키는 서버에만 둡니다. 기존 OpenAI 키·Cloudflare AI 키는 재사용하지 않습니다.
확인일 기준 Groq 공식 표에는 후보 두 모델 모두 30 RPM·1,000 RPD·8,000 TPM·200,000 TPD와 strict JSON 출력 지원이 기재돼 있습니다. 계정별 실제 콘솔·응답 헤더가 우선이며 일일 분석 횟수를 보장하지 않습니다. 입력·출력·추론 토큰·자료 대조·평가 호출을 함께 예산에 포함합니다.
운영 계정은 Groq의 18세 이상 요건을 충족해야 합니다. 청소년 대상 애플리케이션의 별도 요건과 모델 이용 조건을 확인하기 전에는 실시간 분석을 활성화하지 않습니다. 학생에게 연령을 속여 가입하도록 요구하지 않습니다. 성인 지도자 계정이 있다는 사실만으로 모든 사용 조건이 충족됐다고 간주하지 않습니다.
Gemini는 청소년이 사용할 가능성이 있는 서비스에 대한 현재 API 약관 때문에 예비 경로에서 제외합니다. GitHub Models는 2026-07-30 종료되어 후보에서 제외합니다. Cerebras·OpenRouter·K-EXAONE은 현재 계정·구조화 출력·이용 조건·한도를 검증하지 않았으므로 자동 예비 서비스로 넣지 않습니다. 로컬 공개 LLM은 개발·비상 시연용 선택지이며 사용자 PC 상시 서버를 기본으로 삼지 않습니다.
실패 때 다른 사업자로 원문을 자동 전송하거나 유료 모델로 전환하지 않습니다. Groq 사용 조건을 충족할 수 없으면 실시간 활성화를 보류하고 브라우저 공개 모델의 성능·용량을 따로 시험합니다.

## 3. MVP 컷라인

| 단계 | 범위 | 필수 여부·완료 조건 |
|---|---|---|
| M0 예시 UI·계약 | 핵심 4종 이상, 현재 보유 6종 예시; 3축 통합 성분표·원문 클릭·실패 상태 | 필수. 학습용 예시를 실제 분석으로 표시하지 않음 |
| M1 실제 LLM·인용 검증 | 논점·표현·사실 주장 추출, 문장 인용 검사, 서버 집계, 선택 주장 1개와 입력 자료 대조 | 필수. 실제 한국어 입력·자료 상충·불충분·한도 오류 확인 |
| M2 임베딩·PCA | 공개 사전학습 임베딩, 대표 문장과 PC 분포 시연 | 선택. PCA 축을 정치·찬반·도덕 축으로 해석하지 않음 |
| M3 SVM 비교 파일럿 | 한 과제의 소규모 사람 라벨, 규칙·LLM 단독·임베딩+SVM 비교 | 선택. 비교 표와 사람 2명 일치도, 실제 결과만 보고 |

필수 완료는 M0+M1입니다. 확장 프로그램·자동 페이지 감지·웹 전체 검색·URL 본문 자동 수집·범용 사실 판정·학습 모델 공개 배포·개인화 추천은 MVP 밖입니다. 자료 URL은 메타데이터로 남길 수 있지만, 본문을 취득하지 않았다면 읽었다고 표시하지 않습니다. 브라우저 확장은 발전 계획으로만 둡니다.
M2/M3 결과가 없더라도 있다고 꾸미지 않습니다. 최종 발표에는 미실시를 표시하고, 가능하면 작은 사람 평가와 비교 표를 우선합니다. 평가 기준은 아래 §5에서 지금 고정합니다.

## 4. 4주 실행 계획

| 주차 | 제가 진행할 작업 | 팀·사람이 확인할 부분 | 산출물 |
|---|---|---|---|
| 1주 | 3축 계약·통합 화면 정의·Groq 어댑터·한국어 10사례 시험·키 없는 예시 유지 | 계정 사용 자격, 공개·가상 자료 사용 확인 | M0, 모델 비교 로그, JSON·인용 오류 목록 |
| 2주 | M1 기본 분석·자료 대조·토큰 예약·오류·개인정보 입력 경고 | 독립 평가자 2명의 기준 점검 | 실제 분석 MVP, 인용 검증 시연 |
| 3주 | 반응형·성분표·자료 관계 문구·선택 PCA·가능하면 SVM 파일럿 | 라벨 불일치 조정 | UI, 선택 실험·비교 표 |
| 4주 | 동결 평가·지연·무료 한도·호스팅 검사·발표·장애 시연 | 설명 적절성·성능 한계 검토 | 수용 보고서, 녹화/예시 비상 시연 |

날짜는 2026년 11월 4주 작업을 가정한 계획이며 실제 마감 공고가 확인되면 역산합니다. 코드·데이터 형식·자료 조사·실험 실행·문서 수정은 제가 진행합니다. 독립적인 사람 평가를 제가 대신 수행했다고 주장하지 않습니다. 사람이 필요한 부분만 구체적으로 분리합니다.

## 5. 미리 정한 수용 기준

- 한국어 10사례 선별 시험: 모델별 JSON 형식 유효율 9/10 이상, 화면에 채택된 인용의 원문 일치 100%, 실패·유보 숨김 없음. 선별 시험은 제품 정확도 근거가 아닙니다.
- 동결 평가: 사람 2명이 독립 검토한 문장 60개 이상, 최소 15개 원문/스레드 그룹을 포함합니다. 공격 표현·중립적 반대·인용·반어·정보 부족을 포함하고, 같은 그룹을 개발/시험에 나누지 않습니다. 작은 표본임을 명시합니다.
- 표현 과제의 미리 정한 목표: 동결 시험 macro-F1 0.75 이상, flagged precision 0.80 이상, 처리율 0.80 이상. 유보를 오답/미처리로 포함한 전체 집계와 유보 제외 집계를 둘 다 보고합니다. 목표 미달이면 해당 과제는 실험 기능으로 표시합니다.
- 논점·해설·주장-자료 관계는 각각 사람 평가를 실시합니다. 자료 대조 20쌍 이상에서 관계 해석 적절성 80% 이상을 목표로 하며 표본·분모·유보를 공개합니다. 과제 간 지표를 섞어 평균 정확도를 만들지 않습니다.
- 사람 일치도: 조정 전 단순 일치율·Cohen kappa·평가 건수·라벨 분포를 보고합니다. kappa 0.60 미만이면 지침을 재검토하고 변경 전후 평가를 구분합니다. 이 값은 목표이지 달성 결과가 아닙니다.
- 위조·원문 밖 인용·잘못된 분모·허위 취득 출처는 출시 검증에서 0건이어야 합니다. 인용 일치는 해석 정확성을 증명하지 않습니다.
- 앱 전체 40초 마감, 공급자 호출 25초 마감으로 시작해 배포 환경에서 확인합니다. 성공 요청 p95 30초 이하를 목표로 하며 timeout·실패율과 실제 표본 수도 함께 공개합니다. 달성 전 완료로 표시하지 않습니다.

SVM 파일럿을 할 때만 train/calibration/dev/test를 그룹별로 나눕니다. 최소 학습·평가 클래스 수가 확보되지 않으면 SVM 결과를 생성하지 않습니다. LLM 자동 라벨을 최종 사람 정답으로 쓰지 않습니다. SVM margin은 보정·독립 검증 전 확률이 아닙니다.

## 6. 수치·근거·성분표

세 축 이름은 항상 **논점 분포 / 자극성 / 근거 충분성**입니다. 현재는 건수와 규칙으로 정한 상태를 기본 표시하고, 건수로 계산한 비율은 분모와 함께 선택 표시합니다. 예: 자극성 ‘검토 표현 있음 · 3/12문장’, 근거 충분성 ‘자료 대조 2/5주장’. 집계 비율 25%는 보정이 없어도 계산할 수 있으나 ‘공격적일 확률 25%’로 바꾸지 않습니다.
보정 후에도 진실·편향 확률을 자동으로 만들지 않습니다. 합성 34/66·90% 컨셉 수치는 기능 예시임을 표시하거나 삭제합니다. 논점 비율은 다중 배정으로 합이 100%를 넘을 수 있으며 사회 전체 여론이 아닙니다.
관점 확장은 빠진 논점 후보와 검토 질문으로 한정합니다. 신고·피드백은 검토 기록 내보내기이며 자동 재학습·판단 기준 변경은 하지 않습니다. 팀이 받은 자료를 검토한 뒤 지침·버전을 바꿉니다.

## 7. 활동계획서에 넣을 교체 문안

이 절은 제출용 원본 PDF의 활용 기술 표·Ⅳ-1·구조도에 옮겨 쓸 개정 문안입니다. 원본 PDF 파일은 덮어쓰지 않았습니다.

### 활용 기술 표

| 기술 | 역할 |
|---|---|
| 무료 사전학습 LLM | 논점·표현·주장과 정확한 원문 인용 후보 추출 |
| 임베딩 + PCA | 댓글의 의미 벡터와 분포 탐색·시각화, 선택 시연 |
| SVM | 사람 라벨이 확보된 한 과제의 소규모 비교 분류 실험 |
| 인용 검증·집계 | 원문 구간 일치·참조 검사, 상태·분자·분모 계산 |
| 웹 UI | 논점 분포·자극성·근거 충분성의 3축 성분표와 근거 클릭 |

Moderation API를 이용한 사전 검수·게시 차단은 포함하지 않습니다. 별도 XAI를 약속하는 대신 인용·출처·해석 평가를 제시합니다.

### Ⅳ-1 서비스 동작

‘사용자가 공개 자료나 가상 글·댓글을 붙여 넣으면 AI가 논점과 표현, 확인할 주장을 분석한다. 웹사이트는 논점 분포·자극성·근거 충분성을 한 성분표에 표시하고, 근거 문장을 누르면 해당 원문 구간을 보여 준다. 사용자는 선택한 주장에 참고자료를 입력해 관계를 비교하고, 빠진 논점을 살펴볼 검토 질문을 확인한다. 결과는 판단을 돕는 제안이며 글을 삭제하거나 게시를 차단하지 않는다.’
링크만 입력해서 본문을 자동 분석하는 기능과 페이지 옆 자동 감지는 발전 계획으로 이동합니다. ‘피드백을 받으면 운영자가 내용을 검토한 뒤 기준·버전을 갱신한다. 자동 재학습은 하지 않는다’로 교정 문구를 통일합니다.

### 구조도 라벨

공개·가상 텍스트 입력 → LLM 논점·표현·주장·인용 추출 → 원문 인용·자료 관계 검증 → **논점 분포 / 자극성 / 근거 충분성** → 원문 확인·검토 질문.
‘신뢰성 검증’은 ‘원문 인용·자료 관계 검증’으로, ‘의미 판단 단계’는 ‘성분표·근거·검토 질문’으로 바꿉니다. 선택 연구는 ‘임베딩 → PCA 탐색 / 라벨 기반 SVM 비교’ 분기로 둡니다.

### 배경 통계·기존 해결 방식 문장

‘방송통신위원회·한국지능정보사회진흥원이 2025년 3월 발표한 2024년도 조사에서 청소년의 사이버폭력 경험 종합 비율은 42.7%였다.’ 가해만·피해만·가해와 피해 모두를 포함한 수치이며 피해 경험만의 수치로 쓰지 않습니다. 기존 42.3%를 이 조사 수치라고 표기하지 않습니다.
기존 해결 방식 정리: ‘차단·필터링 중심 도구와 달리, 이 서비스는 원문 근거와 항목별 분석을 제시해 사용자가 스스로 검토하도록 돕는다.’

## 8. 개인정보·호스팅·현재 상태

시연 자료는 가상 또는 사용 가능한 공개 자료만 사용합니다. 비공개 대화·개인정보는 입력하지 않도록 경고하며, 탐지 가능한 전화번호·이메일 등의 입력은 분석 요청 전에 차단·수정 안내합니다. 탐지로 모든 개인정보를 보장해 제거할 수는 없습니다. 대회 공고·규정 원문을 확보하기 전 ‘규정 준수 인증 완료’라고 쓰지 않습니다.
무료 LLM API를 사용하려면 키·요청 제한을 보관하는 서버가 필요합니다. 기존 Sites 서버를 우선 재사용하고 비용 조건·실행 시간·CPU·메모리·프록시 제한을 확인합니다. GitHub는 코드 보관에 쓸 수 있지만 GitHub Pages만으로 서버 비밀키 경로를 대체하지 못합니다. 단일 서버 시연에서는 메모리 제한기를 쓸 수 있으나 재시작 시 초기화되므로 공개 분산 운영에는 D1 등 공유 원자적 저장소를 씁니다.
현재 v4의 Groq 어댑터·무료 한도 보호·입력 제한·전송 동의·개인정보 검사·축/관계 문구·통합 요약을 구현했습니다. 실제 Groq 키·호출·한국어 품질 검증은 아직 없습니다. 세 문서 개정과 실제 코드 이행을 구분합니다. 기존 SVM 코드는 삭제하지 않고 선택 M3 실험으로 보관합니다.

## 추가 운영 방침: 지금은 무료, 유료는 나중에 명시적으로 전환

현재는 Groq Free만 구현·검증하며 `FREE_ONLY=true`, `ENABLE_PAID_PROVIDER=false`, `PAID_ACTIVATION_CONFIRMED=false`를 기본으로 둡니다. Groq 키·운영 조건이 준비되지 않아 실시간 활성화는 아직 안 됐습니다. 기존 OpenAI 키를 생성·이동·업로드·호출하지 않습니다. 무료 한도 초과 시 유료 fallback은 없습니다.
향후 사용자가 전환을 명시하면 기존 OpenAI 키의 승인된 저장 위치를 재사용할 수 있지만, 키가 존재한다는 사실만으로 호출하지 않습니다. 무료 전용 해제 + 별도 유료 활성화 + 명시적 전환 확인을 서버에서 모두 검사하며, 그때 OpenAI 어댑터 구현/등록·모델 선정·비용 예산·전송 안내·같은 한국어/JSON/인용 시험을 함께 완료합니다. 현재는 해당 어댑터가 등록되지 않아 유료 플래그만 바꿔도 호출할 수 없습니다.
공통 분석 결과·인용 검증·집계 계약은 유지하고, 제공자 고유 요청 형식·시간 제한·사용량 처리는 서버 어댑터에 둡니다. AI 제공자 전환과 호스팅 전환은 별개입니다.
