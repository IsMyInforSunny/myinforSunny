## 매체 좌표·절댓값

`lib/media-position.ts`는 실제 Claude CLI가 구현했고 Codex가 통합·시험했다. 옆 Claude 세션 `pp-df`에는 분담·진행 메시지를 전송했다. 해당 세션의 수신 확인을 CLI 작업 완료와 혼동하지 않는다.

- 명제별로 비교한다. 반대 `-1`, 맥락 보충 `0`, 찬성 `+1`은 위치 부호다. 0이 중립·객관성 인증은 아니다.
- 정확히 같은 명제를 다룬 고유 기사 3개 이상일 때 매체별 평균 위치를 표시한다. 한 기사로 매체 전체의 성향을 확정하지 않는다.
- 기준선은 적격 매체 2곳 이상에서 매체별 평균을 동일 가중으로 평균한다. 최소 건수는 계산상의 조건이며 대표성·통계적 검증을 보장하지 않는다.
- 입력 기사의 명제에 대한 입장은 사용자가 직접 지정한다. 자동으로 정치 성향을 추측하지 않는다.
- 차이는 `abs(직접 지정한 입력 입장 − 관측 매체 기준선)`이다. 범위는 0~2이며 신뢰 확률·진실 점수·보정된 정치 편향 지수가 아니다.
- 실제 기사 좌표는 웹 취득·인용 검증된 결과로만 구성한다. URL 중복·상충 분류를 제외하고 명제를 섞지 않는다. 기간·주제·검색 노출의 선택 편향이 남는다.
- 자료가 부족하면 계산 대기다. 가상 교내신문 A·B 6개 기사는 별도 체험 버튼으로만 표시하며 실제 매체와 구분한다.

## 출처 품질 연결

Claude 출처 관찰 모듈 `lib/source-quality.ts`를 서버 검색과 자료 상태 UI에 연결했다. 다른 매체를 우선하되 한 조사 쿼리의 취득은 최대 2회로 유지한다. 동일·유사한 긴 본문의 전재 후보를 추가 근거에서 제외한다. 짧은 공통 문구로 전재를 확정하지 않으며 다른 도메인도 독립 출처라고 단정하지 않는다.

자료 상태 화면은 현재 분석 ID가 일치하는 결과만 집계하고 실제 웹 취득·수동 입력·가상 자료를 분리한다. 발행일 불명·잘림·중복 후보를 표시하되 기존 자료 대조 판정을 승격시키지 않는다. 출처 관찰 결과는 신뢰 점수가 아니다.

## 모듈과 검증

- `components/canva-dashboard.tsx`, `app/canva-dashboard.css`: 대시보드·버튼·게이지.
- `components/media-position-map.tsx`, `lib/media-position.ts`: 매체 좌표·직접 지정 입장·절댓값.
- `components/source-observations.tsx`, `lib/source-observations.ts`: 현재 분석에 묶인 자료 상태.
- `lib/server/research.ts`: 취득 제한·출처 다양화·본문 중복 후보 제외·서명된 발췌.
- `components/workbench.tsx`: 공용 UI 배선, 연구 결과를 현재 keyed 분석 ID에 연결, 로그 오류 분류.

252개 자동 시험 통과, 실제 API를 쓰는 13개는 건너뜀. TypeScript 통과. Playwright에서 가상 좌표의 절댓값 1.000, 상세 펼치기, 팝업 375px 가로 넘침 없음, 대조 진행 1/1을 확인했다. SVG 좌표를 소수 3자리로 고정해 서버·브라우저 삼각함수 오차에 따른 hydration 경고를 수정했다.

운영 외부 검색은 아직 비활성이다. Firecrawl 키·무료 한도·매체별 이용 조건과 실제 수집 시험은 별도다. BAZE는 개발용 코딩 에이전트 설정이며 웹사이트의 Groq 분석 제공자 설정과 별개다.
