# 내 정보 맑음? — 개발계획 v3.0

2026-10-30 · 현재 기준 문서. 기술명세 v3.0·아키텍처 v3.0과 함께 적용합니다.
기존 v2의 외부 생성 AI 중심 기본 분석과 Cloudflare Workers AI 가입·키 설정 절차를 대체합니다. 원본 PDF·PPT 파일 자체는 수정하지 않습니다.

## 1. 목표와 원본의 정확한 해석

청소년이 본문과 댓글의 논점·표현·근거를 살펴보고 자율적으로 판단하도록 돕습니다. 삭제·검열·사용자 이념 판정 기능은 만들지 않습니다.
멘토링 PPT 2·4장은 사전학습 LLM·임베딩으로 언어 이해를 활용하고 팀은 측정·설명·검증을 구현하라고 제안합니다. 4·6·7장과 노트는 PCA를 탐색, SVM을 사람 라벨이 필요한 지도학습, 확률 보정을 별도 검증 대상으로 구분합니다. PPT가 언어모델 전체를 처음부터 학습하라고 요구한다는 이전 설명은 잘못됐습니다.
사용자의 추가 조건은 외부 AI API 결제 없이, 개발자 PC가 꺼져도 공개 사이트를 사용하는 것입니다. 따라서 API 호출 제안은 채택하지 않고 **공개 사전학습 임베딩을 기기에서 실행 + 직접 학습한 분류기 + 검증 가능한 수학적 집계**로 구현합니다. 이 선택은 PPT 문구 그대로가 아니라 비용 조건에 맞춘 구현 결정입니다.

## 2. 직접 구현하는 범위

| 부분 | 구현 책임과 산출물 |
|---|---|
| 자료 | 사용 조건·출처·삭제 기준·그룹 ID·분할·라벨 이력 데이터 계약 |
| 언어 특징 | 공개 임베딩 모델의 한국어 품질·라이선스 확인, 모델 revision·토크나이저·pooling·정규화 고정 |
| 자체 모델 | 논점 다중 분류, 명제-댓글 입장 분류, 문장 표현 분류, 주장-자료 관계 분류를 과제별로 학습 |
| 수학 엔진 | 기준선·SVM 학습, 보정, 유보, PCA 탐색, 분자·분모 계산 |
| 설명 | 실제 원문 구간·기준 정의·기여 특징. 생성한 해설을 SVM의 실제 이유로 가장하지 않음 |
| 서비스 | 모델 로딩·브라우저 추론·실패 처리·정보 성분표·사용자 자료 대조 |
| 검증 | 누수 차단·모델별 비교·실행 시간·메모리·한계와 모델 카드 |

공개 임베딩의 사전학습까지 팀이 했다고 주장하지 않습니다. 외부 AI API를 연결한 것만으로 자체 모델 구현이 완료됐다고 주장하지 않습니다.

## 3. 기능과 데이터의 순서

1. **표현 분류부터 실제 파이프라인 완성:** 문장 단위 clear/flagged 기준선, 한국어 임베딩+선형 SVM, 독립 calibration split의 보정, dev에서 유보 임계값 선택, 고정 test 평가. 이 단계는 다른 두 축을 완성했다는 뜻이 아닙니다.
2. **논점·입장:** 우선 학교생활 등 명시한 범위에서 논점 사전을 정의하고 multi-label SVM을 학습합니다. 입장은 명제와 댓글의 쌍을 입력해 별도 학습합니다. 범위 밖 주제·모호한 문장은 유보합니다. 범용 논점 자동 발견을 고정 라벨 분류와 혼동하지 않습니다.
3. **근거 관계:** 사용자가 주장과 원문 구간을 선택·수정하고 참고자료를 붙여 넣습니다. 문장 임베딩 검색은 후보 정렬에만 사용합니다. supports/contradicts/context/insufficient 관계 모델은 별도 라벨·시험을 사용합니다. 유사도만으로 사실을 판정하지 않습니다. 자동 주장 추출은 별도 모델 평가를 통과해야 활성화합니다.
4. **PCA:** 임베딩 분포·대표 댓글·라벨을 함께 탐색합니다. PC1·PC2를 찬반/자극성 축으로 이름 붙이지 않습니다. 분류용 차원축소는 별도 train-only fit 실험으로 결정합니다.
5. **브라우저 배포:** 승인된 encoder와 과제별 head를 Web Worker에서 실행합니다. 작은 TF-IDF 기준선을 먼저 이식해 Python/브라우저 점수를 비교하고, 임베딩 경로의 parity·속도·메모리를 확인합니다. 적합하지 않으면 지표를 숨기고 경량화부터 개선합니다. 유료 API로 우회하지 않습니다.

## 4. 개발 단계와 완료 조건

| 단계 | 작업 | 완료 조건 |
|---|---|---|
| M0 방향 복구 | 세 문서 개정, 외부 AI 호출 비활성, 예시/학습 모델 상태 구분 | 키 요구 없이 실행, 외부 inference 요청 없음 |
| M1 엔진 골격 | 라벨 계약·검사·SVM 학습·보정·artifact 내보내기·PCA | 합성 자료로 코드 시험 통과. 합성 성능을 제품 성능으로 인용하지 않음 |
| M2 한국어 평가 | 사용 가능한 자료 선정·독립 라벨·동결 분할·기준선 비교 | 자료 계보·평가 보고서·오류 사례 확보 |
| M3 세 과제 확장 | 논점/입장/근거 과제별 head·유보·근거 연결 | 과제별 test 및 coverage 확인. 표현 모델 성능으로 다른 과제 성능 대체 금지 |
| M4 웹 추론 | Web Worker·모델 캐시·취소·정보 성분표·자료 대조 | 임의 한국어 입력으로 실제 학습 모델이 동작, 원문 밖 근거 없음 |
| M5 공개 시연 | 무료 정적 호스팅 후보 실측·모바일·확장 연결 | 개발자 PC 종료 후 공개 주소 기능 확인, 다운로드·메모리·지연 기록 |

M0~M1은 제가 바로 수행합니다. M2에서 제가 작성한 초안 라벨은 reviewed로 승격하지 않습니다. 사용자가 모든 라벨을 직접 만들도록 요구하지 않으며, 공개 사람 라벨 자료의 사용 조건과 과제 적합성을 먼저 확인하고 필요한 추가 검토만 요청합니다. 사람을 가장해 평가자 서명을 만들지 않습니다.

## 5. 데이터 및 평가 계획

- 원문 수집은 허용된 공개 자료·팀 작성 자료·명시적 동의 자료로 제한하고 출처와 라이선스를 기록합니다. 서비스 입력은 자동 수집·학습하지 않습니다.
- train/calibration/dev/test 네 분할을 문서·스레드·재게시 그룹 단위로 고정합니다. 동일·유사 문장과 같은 원문에서 잘라낸 문장의 누수를 검사합니다.
- 사전학습 encoder는 고정하고 학습 자료로 scaler와 head만 학습합니다. calibration은 보정만, dev는 선택만, test는 동결된 모델 평가만 수행합니다.
- 규칙, TF-IDF+선형 SVM, 임베딩+로지스틱 회귀, 임베딩+선형 SVM을 비교합니다. 외부 LLM API 실험은 현재 범위에서 제외합니다.
- 과제별 macro-F1·클래스별 precision/recall·혼동행렬·유보율·처리율을 공개합니다. 보정 시 Brier score·ECE와 reliability diagram을 추가합니다. 모든 지표를 전체와 유보 제외 기준으로 구분합니다.
- 소수 클래스·인용·풍자·위협·중립적 반대·자료 충돌·시점 불일치를 포함합니다. 독립 데이터가 부족하면 정확도를 약속하지 않습니다.

## 6. 일정·비용·유지 조건

4주 가정: 1주 M0~M1·자료 조사, 2주 M2·표현 분류, 3주 M3·M4, 4주 실측·오류 수정·시연. 날짜는 확약이 아니며 데이터 확보 상태에 따라 조정합니다. 일정 부족 시 범위를 명시한 부분 결과를 제공하며 라벨·검증을 생략하고 세 축 완료로 표시하지 않습니다.
API 호출료는 발생시키지 않습니다. 모델 학습·다운로드·기기 연산에는 시간·네트워크·전력·저장공간이 필요합니다. 무료 공개 운영은 정적 호스팅의 파일 크기·트래픽 및 모델 배포 라이선스를 확인한 뒤 확정합니다. GitHub Pages는 후보이며 현재 사이트를 이미 이관했다고 주장하지 않습니다.

## 7. 현재 상태와 다음 산출물

기존 화면·예시·원문 구간·지표·JSON 내보내기는 재사용합니다. 기존 API 기반 자동 논점·해설은 새 모델의 결과로 재사용하지 않습니다. 아직 독립 한국어 학습 자료·운영 모델·실측 성능은 없습니다.
다음 산출물은 research의 재현 가능한 SVM 학습·보정·내보내기 코드, 라벨 지침, 평가용 스키마와 실험 보고서입니다. 예시·합성 시험·사람 검토·실제 배포 모델을 각각 명확하게 표시합니다.
