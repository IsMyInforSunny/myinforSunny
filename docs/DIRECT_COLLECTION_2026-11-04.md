## 실제 SVM 자료 진단

실제 원문에서 발행 사이트를 정답으로 하는 문자 TF-IDF(2~4글자) + LinearSVC 실험을 로컬에서 수행했다. 원전·의대·임금의 3개 주제로 57건을 학습하고, 전기요금·주택·연금의 다른 3개 주제로 55건을 평가했다. 학습·평가의 주제 및 동일 원문 해시는 겹치지 않았다.

주제 검토가 필요한 1건과 주제별 표본이 부족한 뉴데일리 본지 7건을 제외해 112건을 사용했다. 평가 클래스는 프레시안·오마이뉴스·데일리안·뉴데일리경제 4개다.

| 실제 실험 입력 | 매체 분류 정확도 | Macro F1 |
| --- | ---: | ---: |
| 수집 원문 | 67.27% | 0.6589 |
| 매체명·저작권 꼬리 문구 제거 | 65.45% | 0.6397 |

이 수치는 **매체 분류 성능**이다. 정치적 편향 정확도, 진실 확률, 이용 승인이나 사람 평가 결과가 아니다. SVM 가중치에서 얻은 첫 좌표 성분은 임의의 수학적 방향이며 정치 축으로 검토되지 않았다. 연구용 파일은 생산 모델과 다른 스키마이고 `lib/data/bias-model.json`은 여전히 `null`이다.

## 기준 매체 차이로 만든 좌표 후보

사용자가 요청한 상대 기준 축을 검토하기 위해 선택형 `anchor_contrast` 투영을 추가했다. 이미 학습한 매체별 SVM 분류 계수에서 기준 집합 B의 매체 평균과 기준 집합 A의 매체 평균의 차이를 구한다. 매체별 점수를 미리 고정하는 방식이 아니다. 기존 SVD 방식은 기본값으로 유지하고, 투영 방식과 기준 매체가 달라지면 모델 버전도 달라진다.

로컬 실험은 A={오마이뉴스, 프레시안}, B={데일리안}을 **미검토 기준 가설**로 입력했고, 뉴데일리경제는 기준 집합에 넣지 않았다. 정치 라벨을 승인하거나 생산용 매체 기준표를 바꾸지 않았다. 같은 55개 평가 기사에서 얻은 매체별 중심은 다음과 같다.

| 매체 후보 | 평가 기사 좌표 평균 |
| --- | ---: |
| 오마이뉴스 | -0.166177 |
| 프레시안 | -0.133791 |
| 뉴데일리경제 | 0.021114 |
| 데일리안 | 0.089787 |

이 표는 입력한 두 기준 집합의 **매체별 평균 순서**가 분리됐다는 실험 결과다. 개별 기사의 정치적 편향 정확도가 입증됐다는 뜻은 아니다. 기사 간 겹침, 연도·장르 영향, 기준 매체 적합성, 사용 조건과 실제 독립 평가자의 축 검토가 남아 있다.

- 후보 버전: `134cf0812ce0c2f30dce`
- 분류기 수치 지문: `49aff3e79c1c685ad8d96e1805c08aed8ce938132c6dd191b4c9955be8b92c81`
- 로컬 결과: `.sites-runtime/publisher-anchor-contrast-20261104-01/`
- `coordinate-references.local.json`에 정확한 후보 버전과 평가 기사별 좌표를 보관했다. 사람 평가나 생산 승인으로 채우지 않았다.

## 수집으로 찾아 고친 구현 문제

오마이뉴스 공개 기사의 전체 문서를 감싼 정확한 `aspnetForm`을 기존 추출기가 제거해 기사 본문까지 잃던 문제를 수정했다. 실제 공개 본문 영역 `div.at_contents`를 인식하고, 외부 폼 안의 명시적 div 본문을 유지하되 주변 기자·후원 영역은 제외한다. noai·nosnippet·유료 접근 제한 검사는 유지한다. 모바일 프레시안·오마이뉴스의 발행 매체 별칭도 자료 준비기에 추가했다.
