### P4의 계산 방식 (기한 안에 숫자가 나오게 하는 장치)
- 기본: 분석 LLM 호출에서 문장별 `찬성 쪽/반대 쪽/중립/유보`와 `기자/취재원`을 문장 번호+기호로 받는다(`lib/sentence-voice.ts`의 `VOICE_INSTRUCTIONS`·`method:'ai'` 경로 사용). 쟁점은 기사 단위 규칙으로 정한다.
- 표시 이름은 "인용 균형(AI 문장 분류)". "편향 점수"·"정확도"라고 쓰지 않는다. 건수와 분모, 유보 수, 가능한 범위(`voiceEvidenceBounds`)를 함께 보여 준다.
- 방향 문장이 3개 미만이면 "찬반 문장이 n개뿐이라 균형을 계산하지 않습니다".
- 6개 주제 밖 기사는 LLM이 정한 명제가 당위형일 때만 계산하고 아니면 "비교할 논점 없음".
- 11-19에 SVM 후보가 게이트를 통과하면 로컬 연구 빌드에서 SVM 결과를 나란히 보여 준다. 공개 사이트의 SVM 적용은 이용 검토 결정 뒤 2차 배포.
