# 내 정보 맑음? — 개발계획 v4.1

2026-10-30. 현재 개발 기준. 기술명세·아키텍처 v4.1과 함께 적용합니다.

## 방향
기사를 입력해 3축 성분표를 만들고, 수치의 분모와 원문 인용을 확인하며, 다른 관점과 실제 관련 기사를 통해 검토 범위를 넓히는 웹사이트입니다. 멘토 PPT의 사전학습 LLM 활용·인용 중심 설명·외부 평가를 유지합니다. PCA는 임베딩 탐색, SVM은 라벨이 있을 때의 비교 연구입니다. NLP 전체 직접 학습은 필수가 아닙니다.

## 구현 순서와 현재 상태
1. 오류 수정·예시 회귀: 출처 없는 수치를 factual로 추출하되 진실로 확정하지 않습니다. 7종 가상 예시와 자료의 두 인용을 검사합니다. 코드 구현 및 자동 시험 완료.
2. 한도·개인정보·UI: IP 3회/분·20회/시간, 콘솔 한도의 80% 이하 일일 예산, 60초 마감, 소진 시 예시 안내, 분모 0·소표본 표시, 포커스 이동. 코드 구현 및 자동 시험 완료, 배포 브라우저 확인은 별도 기록합니다.
3. 실제 LLM 시험: 서버 Groq 키 등록·호출 성공. 수치 주장 유형과 인용된 명제 대조 문제를 고쳤고 실제 추가 시험에서 불충분으로 이어짐을 확인했습니다. 이는 독립 정확도 평가가 아닙니다.
4. 다른 관점: AI 제안·출처 없음, 원문 대상·검토할 자료 표시. 출처 인용은 검증된 자료와 링크가 있을 때만 표시합니다. 구현 및 회귀 검사 대상입니다.
5. 평가 준비: 학교생활 가상 자료 40개, 독립 평가자 2명 CSV, 비교 스크립트. 준비 완료, 사람 라벨·독립 평가 결과는 미실시입니다. 팀이 실제 라벨을 작성해야 합니다.
6. 관련 기사: 최종 목표에 포함합니다. 현재는 검색 후보 어댑터만 준비했으며 약관·무료 한도·연령·허용 용도 검토, 사용자 승인, 정상 검색 실증이 필요합니다. 활성화하지 않습니다. 대회 시연에는 추후 기능이라고 적습니다.
7. 문서·배포: 개발계획·명세·아키텍처·활동계획서 교체 문안을 동일 기준으로 갱신하고 검증된 빌드를 배포합니다.

## 출시 기준과 미확인 항목
자동 시험과 실제 호출, 원문 인용·집계 검사가 제품 정확도를 증명하지 않습니다. 외부 평가자 2명은 서로의 라벨과 LLM 결과를 보기 전 독립 평가합니다. 현재 40사례는 중심 주장 파일럿이며 기존 동결 60문장·자료 관계 20쌍 기준을 대체 달성한 것으로 간주하지 않습니다.

브라우저 3페이지 오류·375px 결과 이동·키 비노출·입력 로그 부재는 각각 실제 증거를 남깁니다. 한 항목의 시험 통과를 전체 완료로 확대하지 않습니다. 앱 전체 목표는 관련 기사와 독립 평가까지 포함하므로 이들 미확인 상태에서 전체 완료로 보고하지 않습니다.

## 비용·역할
무료 Groq만 사용하며 유료 자동 전환을 하지 않습니다. 확인된 계정 한도는 30 RPM·1,000 RPD·8,000 TPM·200,000 TPD입니다. 앱은 일일 120,000토큰·500회로 제한합니다. 계정 조건과 청소년 앱 조건은 사용자 확인 완료입니다. 코드·시험·문서·배포는 제가 진행하고 사람 정답·새 서비스 승인은 실제 사용자/평가자의 입력으로 받습니다. Claude 연동은 후속이며 현재 개발을 기다리게 하지 않습니다.

## 11월 평가 계획
11월 첫 주에 40개 자료를 2명이 독립 라벨링하고 누락·불일치를 확인합니다. 다음 주에 합의 전 일치도와 실제 LLM 결과를 비교하고 모호한 지침을 수정합니다. 이후 별도 동결 자료를 확보해 주장-자료 관계와 문장 표현 성능을 평가합니다. 실제 마감 공고에 맞춰 일정을 조정하며 미실시 결과를 만들지 않습니다.
