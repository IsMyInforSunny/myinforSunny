# 신뢰 점수와 기사 인용 출처 확인

## 두 가지 지표

`descriptive-scores-2.0`부터 메인 신뢰 숫자는 **출처 가중 근거 점수**다. 기존 출처 명시 점수는 `scores.attribution`이라는 보조 정보로 유지한다. JSON 스키마는2.5이며 이전2.4의 `scores.reliability`와 의미가 다르다.

- **출처 가중 근거 점수:** 현재 기사에서 추출한 사실 주장을 실제 취득 원문과 대조한 결과에 공개 출처 가중치를 적용한다.
- **출처 명시 점수:** 이름 있는 근거 출처가 기사 문장에서 연결된 사실 주장의 비율이다. 그 출처의 실재·정확도·발언 일치를 판정한 점수가 아니다.

## 메인 점수 계산

1. 현재 분석ID와 live 모드가 일치하는 조사 결과만 사용한다. 같은 주장의 최신 재조사가 실패하면 이전 성공으로 채우지 않는다.
2. 공개 HTTPS에서 취득한 본문, 본문 범위와 정확히 일치하는 인용, `temporalFit=matched`인 관계만 가중 근거로 사용한다. 시점 검토와 발행일 메타데이터의 유무는 별도 확인 항목이다.
3. Reuters DNR 2025 한국 브랜드 신뢰 응답을 공개 보조 가중치로 사용한다. MBC0.61 등14개 매체 값과 분모·척도·범위는 기존 방법 문서를 따른다. 이용자 인식을 사실 정확도 측정으로 바꾸지 않는다.
4. 매체당 총 기여도는 한 가중치 안에서 나누고, 같은 원본 집단을 여러 매체가 전재해도 원본 수를 부풀리지 않는다.
5. 주장별로 가중치가 모두 확인되고 최소2개 매체와2개 원본 근거 집단이 있어야 가중 구성을 계산한다. 미등록 가중치가 섞이면 그 주장을 보류한다.
6. 각 주장의 가중 뒷받침 비중을 사실 주장마다 같은 비중으로 평균해100을 곱하고 정수 점수로 표시한다.

예를 들어 **합성 검사**에서 두 출처의 가중치가0.7과0.3이고 각각 뒷받침과 상충이면, 그 주장에 대한 점수는70점이다. 모든 자료가 뒷받침이면 검토 자료 안의 구성은100점이 될 수 있다. 작은 검토 표본을 넘어 기사 전체가 참이라고 단정하는 값이 아니다.

## 부족한 자료와 범위

- 사실 주장이 없으면 `해당 없음`이다.
- 가상 예시 또는 대조 가능한 주장이 전혀 없으면 `산출 대기`다.
- 일부만 대조됐으면 전체 사실 주장을 분모에 유지한다. 대조된 주장의 뒷받침 기여도를 하한으로, 나머지가 모두 뒷받침일 때를 상한으로 표시한다. 미대조를0점으로 확정하지 않는다.
- 합성 예: 전체2개 주장 중1개만70점에 해당하면35–85점 범위다. 대조1/2와 근거 집단 수도 함께 표시한다.
- 사용자가 요청한 설명용 점수는 분모가 작아도 원래 건수와 함께 표시한다. 세부 가중 구성의 일반 퍼센트 표에는 기존 분모10개 하한을 유지한다. 두 표현 모두 근거 표본의 제한을 갖는다.

## 기사가 실제로 든 출처의 평가

Claude의 `cited-source-assessment.ts`는 본문에 적힌 유형·구체 이름·1차 자료 신호·자료명·시점과 미확인 사항을 구분한다. 공개 매체명 매핑이나 가중치 등록 자체를 원문 확인으로 취급하지 않는다.

`cited-source-confirmations.ts`는 현재 분석의 취득 자료에서만 확인 기록을 만든다. 출처의 매체 정체성 또는 기사에 명시된 원문URL과, 최소12자 이상의 실제 인용 구절이 모두 맞아야 한다. 단순 관련 기사, 표현만 비슷한 문장, 사용자 입력 자료, 다른 매체, 이전 분석·오래된 재조사는 원 출처 확인으로 올리지 않는다. 짧은 표현이나 같은 뜻의 바꿔 쓰기는 확인되지 않을 수 있다.

원문 확인은 “그 자료에 해당 구절이 있음”을 뜻한다. 기관의 실제 정체성, 인용 내용의 사실 정확도와 인과관계까지 증명하지 않는다. 하나의 출처가 여러 주장에 연결돼 있어도 원문 확인 상태는 주장별로 다시 계산한다.

내보내기는 기본적으로 점수·분모·출처 확인 집계만 포함한다. 입력 원문과 상세 출처 평가는 원문 선택 동의가 있어야 포함하고, 취득 원문URL은 자료·인용 선택 동의를 별도로 따른다.
