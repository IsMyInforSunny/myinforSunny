# 편향 기능 작업 상태

기준일: 2026-11-15. 작업 지시: `docs/CODEX_COMMAND_2026-11-15.md`의 1~9를 순서대로 진행한다. 공개 배포는 하지 않는다. 평가 수치는 **AI 합의 기준이며 사람 정확도가 아님**을 명시한다. 원전 후보의 기존 기준 통과 표시는 **재검증 중**이다.

## 이번 회차의 좁힌 목표

`docs/NEXT_ROUND_GOALS_2026-11-15.md`에 따라 시연 가능한 편향 점수에 집중한다: 우선 4개 쟁점 임베딩 누락 0건, 각 쟁점 전체 기간 비교 집합 1개 이상, 로컬에서 실제 기사 링크로 점수와 반대편 후보 확인, Claude 화면 확인 메모와 마지막 전체 검증 1회. 우선 쟁점 밖 임베딩·분기/반기 조정·속도/캐시 재측정·6개 주제 재학습은 이번 회차에서 하지 않는다. 화면 확인 도구는 다시 시도하지 않고 사용자에게 넘긴다.

## 사용자 결정과 한도 출처

- 범위 기사도 구간 중앙값으로 비교에 포함한다. 기사 방향 문장 ≥3·구간 폭 ≤0.5, 매체당 적격 기사 ≥3·매체 ≥2 조건을 유지한다. 중간점으로 대체하지 않는다.
- Lightning과 Groq `openai/gpt-oss-120b`에 공개 보관 기사 문장을 전송해 합의 라벨을 만든다. 합의 평가 세트는 학습·임계값 선택에서 제외한다. 원본 라벨과 기존 모델은 보존한다.
- NVIDIA 오프라인 임베딩은 일일 예약 상한 없이 전송 시작 간격 ≥20초, 최대 64문장 배치를 사용한다. 429가 발생하면 대기 시점을 기록하고 자동 재시도하지 않는다.
- Groq 마지막 계정 관측 기록: RPM 30, RPD 1,000, TPM 8,000, TPD 200,000. 출처: `docs/GROQ_RESTORE_2026-11-03.md`의 사용자 제공 조직 콘솔 기록 및 `docs/ACTIVATION_READINESS.md:35`. 이는 과거 계정 관측값이며 현재 요금제 또는 프로젝트별 재정의의 확인을 뜻하지 않는다. 무료 요금제의 일반 한도로 가정하지 않는다.
- 현재 프로세스 환경과 canonical 생성 Wrangler 설정에는 Groq 네 한도가 미설정이었으나, 원래 프로젝트 `디지털새싹_cmd/.dev.vars`의 **숫자 설정 항목만** 추가 확인했다. 저장 설정은 `GROQ_CONSOLE_LIMITS_CONFIRMED=true`, RPM=30·RPD=1000·TPM=8000·TPD=200000이다(2026-11-15 확인). 키 값은 조회·출력하지 않았다. 이 값은 현재 저장된 계정 설정이며 콘솔을 새로 조회한 잔여량 관측은 아니다. 추가 사용자 입력 없이 이 설정을 적용할 수 있다. 작업 8의 실제 호출 전에 호출 간격·배치·요청 예약량·잔여량 확인 방법을 아래에 확정한다.
- 공개 사이트를 직접 확인한 현재 모델은 NVIDIA Lightning이므로 Groq 모델별 한도와 공유하지 않는다. 로컬 DeepSeek 실패와 공개 사이트 상태를 구분한다. Groq와 사이트가 같은 한도를 사용하도록 바뀌면 사이트 몫부터 확보한다. 기존 Groq 내부 보호(요청 예약 6,500·분당 7,000·일일 최대 120,000토큰/500회)는 별도이며 계정 설정과 혼동하거나 임의로 해제하지 않는다.

## 2026-11-16 실제 기사 링크 점검

- 우선 4개 쟁점의 임베딩 진행 파일은 `priorityComplete=true`, 각 쟁점 `remainingUniqueSentences=0`이다. 이번 작업에서 큐를 다시 돌리지는 않았다.
- 최종 로컬 연구 산출물 `coordinates-priority-complete/baselines.local.json` 재집계: 전체 기간 적격 묶음은 의대 정원(104건·4개 매체), 최저임금 인상(확인된 묶음 1개), 원전 확대(36건·4개 매체)에서 성립했다. 주택 공급은 7건이지만 데일리안만 매체당 3건 이상(4건) 조건을 만족하여 `insufficient`다. 매체 수 기준을 낮추지 않았다.
- 격리 로컬 빌드 `npm run build` 통과. `/api/capabilities`: NVIDIA 라이브 분석 및 직접 가져오기 사용 가능, 웹 검색 비활성, 연구 비교 `local_research_only`로 확인했다. 공개 번들/배포는 만들지 않았다.
- 실제 기사 URL 분석: 의대 정원 Pressian 기사에서 분석 성공, 전체 기간 비교 `ready`, 0–25점 범위, 비교 표본 104건·4개 매체. 원전 확대 Pressian 기사에서 분석은 부분 완료(기사 작성자 입장 근거 부족 경고), 전체 기간 비교 `ready`, 0–25점 범위, 비교 표본 36건·4개 매체. 두 경우 모두 입력 범위가 기준선과 겹쳐 방향이 `undetermined`이며 반대편 후보는 0건이다. 빈 후보를 만들지 않았다.
- 주택 공급 Dailian 기사: 쟁점은 식별됐으나 기존 분석 캐시 재사용으로 좌표가 없고 비교 집합도 적격 표본 미달이다. 시연 점수를 내지 않는다.
- 최저임금 NewDaily 기사: 실시간 NVIDIA 출력은 출력 길이 제한으로 완료되지 않았다. 저장된 기사 좌표도 유보 17문장·방향문장 0건으로 적격하지 않다. 다른 최저임금 Dailian 기사 재확인에서는 해당 원문이 코퍼스 안에 있어 자기 포함 방지(`input_in_population`)로 비교에서 제외됐다. 비교 규칙을 완화하지 않았다.
- 실제 기사 점검 요약(기사 본문·토큰·키 미포함)은 `.sites-runtime/speed-20261115/demo-bias-2026-11-16.local.json`에 보관한다.
