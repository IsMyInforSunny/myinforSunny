## 점수 해석

- 편향: 기준선과의 상대 좌표 거리(0–2)/2×100. 모델과 비교 표본이 없으면 `산출 대기`다.
- 자극: 검출 문장 비율. 미판정 일부는 범위, 전체 미판정은 `산출 대기`다. 강도·심리 상태를 측정하지 않는다.
- 신뢰: 메인은 `출처 가중 근거 점수`다. 현재 분석의 취득 원문에서 인용·시점이 맞는 근거에 공개 보조 가중치를 적용한다. 대조 가능한 주장이 없으면 `산출 대기`, 사실 주장이 없으면 `해당 없음`이다. 일부만 대조했으면 미대조를 0점으로 확정하지 않고 가능한 범위를 표시한다. 두 주장 중 한 주장만 70점이면 35–85점이다.
- 보조 `근거 출처 명시 점수`는 `scores.attribution`에 유지한다. 기관·기업 이름이 있다는 사실과 실제 내용의 정확성은 다르다. `정부`·`연구팀`처럼 구체적인 이름이 아닌 표현은 명시 출처 분자에서 제외한다.
- 작은 분모에서도 사용자가 요청한 설명용 점수는 원래 건수와 n을 함께 표시한다. 일반 근거 비율의 표본 하한을 낮춘 것은 아니다.
- 실제 출처 신뢰성과 주장 정확도는 원문·시점·인용·독립 자료 대조 및 공개 보조 가중치를 함께 확인한다. 이 과정을 출처 명시 점수 하나로 대신하지 않는다.

## 오전 검증 기록과 오후 변경 범위

다음 전체 검사·브라우저 수치는 오전 버전 기록이다. 오후 점수2.0·내보내기2.5·출처 확인 연결의 통합 검증 결과로 해석하지 않는다. 실제 Groq/검색 연결 확인과 사이트 전체 실제 분석 성공도 별도 검증 대상이다. 최신 검증 결과는 통합 담당자가 갱신한다.

- 로컬 전체 Vitest: 489 통과, 실제 API 선택 검사13개 건너뜀.
- 업로드 후보의 별도 체크아웃: 531 통과, 실제 API 검사13개 건너뜀. 이 체크아웃에 기존 공개 검사2파일이 추가로 남아 있어 로컬 총계와 다르다.
- 두 체크아웃 모두 TypeScript 검사 및 Vinext 빌드 통과.
- Python SVM 인프라 검사7개 통과. 합성 문장 검사이며 실제 정치 편향 정확도가 아니다.
- 브라우저: 7개 예시의 점수·분모·기본/상세 내보내기 일치, 원문 선택 동의, 이전 입력 표시 확인. 375/1280px 메인과 375/560px 방법론·작은 창에 가로 넘침 및 페이지 예외가 없었다.
- 오전 검증 버전: 출처 분류 cited-sources-0.2 · 점수 descriptive-scores-1.1. 오후 구현은 점수 descriptive-scores-2.0 · 내보내기2.5다. 대명사·지시 표현은 미해결로 표시하고 일반 명칭은 이름 있는 출처 점수에서 제외한다.
- 별도 모의 조사·팝업 검증: 취소·늦은 응답 무시·재동의, 실제 JSON 다운로드, 키보드·원문 강조, 예시 취소·초기화, 같은 명제의 관찰 좌표, 긴 문장 경계, 부분/이전 입력과 320–1280px 화면을 확인했다. 외부 API 호출은 하지 않았다.

실제 편향 모델 입력은 `lib/data/bias-model.json`이며 현재 `null`이다. 학습/평가 및 활성화 조건은 `research/BIAS_PIPELINE.md`, 자료 준비 상태는 `research/bias-data-readiness.md`에 기록한다. 학습 기사 URL·본문 해시와 일치하는 참고 자료는 편향 비교용 예측에서 제외하며, 기사별 서명에는 크기가 제한된 모델 식별 정보와 좌표만 담는다.

오후 점수 정의와 출처 확인 조건은 [신뢰 점수 방법](TRUST_SCORE_METHOD_2026-11-03.md)을 따른다. `scores.reliability`의 의미가 이전 내보내기2.4와 달라졌으며 출처 명시는 `scores.attribution`으로 분리했다.

## 오후 통합 검증

타입 검사·548개 자동 검사·빌드 통과, opt-in 실제 API13개는 일반 검사에서 제외했다. 별도 브라우저에서 실제 Groq 요청1회(3871토큰)가 성공했고 가상 문장의 사실1개·의견1개와 자극0점(n=2)을 화면에서 확인했다. 예시7종 점수·JSON2.5·원문 동의·이전 입력·모바일 검증도 통과했다. Python 편향 인프라15개 합성 검사 통과. 전체 로그는 `docs/test-runs/2026-11-03T05-05-28-543Z-website/`다.

공개 사이트 버전20 배포 성공 및 공개 화면의 실제 Groq 분석1회 성공을 확인했다. 배포 서버에는 이미 Groq 비밀 설정이 등록되어 있었고 키 값은 읽거나 교체하지 않았다. 이번 로컬 연결 복구는 [복구 기록](GROQ_RESTORE_2026-11-03.md), 공개 검증은 [배포 기록](DEPLOYMENT_2026-11-03.md)을 따른다.

출처 평가0.2는 매체 전체 이름만 매핑하고, 인용한 매체와 다른 원문 사이트·잘못된 가중치·별칭 중복을 차단한다. 익명·공공기관 출처를 그 발언을 실은 매체로 바꾸어 가중치를 부여하지 않는다. 실제 자료와 검증된 SVM 모델이 없으면 편향과 관련 게이지는 계속 대기한다.

## 2026-11-03 오후 추가 작업 현황

- 실기사 근거 수집 경로에 Firecrawl 공식 도메인 필터, 보수적인 크레딧 사용량 집계, 게시일 파싱 검증을 보강했다. Firecrawl CLI 계정은 아직 인증되지 않아 실제 검색 결과나 실제 수집 성공을 확인하지 못했다. 따라서 공개 사이트의 검색·수집 설정은 계속 비활성 상태다.
- 한국어 검색 질의와 중복 URL·동일 매체 모바일 주소의 소스 선택을 보완했다. 근거가 주장 시점과 맞지 않거나 발행·수집 시점이 불명확하면 결정적 판정을 보류하도록 했다.
- 검증된 인용과 수집 출처가 없는 경우 출처 가중 신뢰 점수에 근거를 더하지 않도록 제한했다.
- 실제 수집 JSONL과 사람의 권리·주제·원문 검토 기록을 준비하는 오프라인 편향 코퍼스 도구를 추가했다. 실제 기사, 리뷰 기록, 모델은 생성하지 않았고 `lib/data/bias-model.json`은 계속 `null`이다.
- 이 변경 뒤 자동 검증은 Vitest 611 통과/13 건너뜀, Python 편향 준비·검토 테스트 24 통과였다. 최종 타입 검사와 제품 빌드도 통과했고 공개 사이트 버전21 배포가 성공했다. 배포 세부사항은 [배포 기록](DEPLOYMENT_2026-11-03.md)에 남겼다.
## 2026-11-03 Claude 검토 후 경계 보완

- 독립 검토에서 발견한 시간 판정 위험을 수정했다. 대상 기간보다 앞선 기사와 명시했지만 파싱할 수 없는 대상 시점은 취득 자료가 뒷받침하는 것으로 확정하지 않는다.
- 검색 질의는 안전한 숫자 표기(`3.5%`, `1.2조`, `서울·부산`)를 허용하고, 외부 검색기로 보내기 전에 한글을 NFC로 정규화한다.
- 편향 코퍼스 준비기는 정확히 일치하는 매체 호스트 또는 소스에 명시한 별칭만 허용한다. 시간대 없는 시각, 미래 발행·취득·검토 시각을 보류한다.
- 수정 후 시점 검증·질의·조사 경로의 Vitest 62개와 Python 자료 준비 테스트 11개가 통과했다. 전체 회귀 검사와 새 빌드는 공개 배포 전 다시 확인한다.

- 모델이 잘못된 선택 검색어를 반환하면 그 제안만 제외하고 핵심 분석을 계속한다.
