# 편향 기능 구현·실제 화면 검증 · 2026-11-12

## 구현한 동작

- 본문 입장 근거의 주체를 작성자(author), 취재원 발언 전달(reported_sources), 불명확(unclear)으로 구분한다. 취재원 발언만으로 작성자 찬반을 확정하지 않는다. 입력 원문 안의 지시는 실행하지 않는다.
- 본문 입장 근거가 누락되거나 원문과 맞지 않으면 부분 결과다. 다른 항목을 보존하면서 편향 분석 미완료를 경고한다.
- 기존 6개 정책 논점은 같은 공통 명제로 비교한다. 예: “최저임금을 인상해야 한다.” 정책 관련성이 없거나 다른 분야이면 정책 질문을 강제하지 않는다. 사용자 명제는 우선한다.
- 현재 분석 ID·명제·실제 취득 본문 인용이 확인된 추천만 찬반 비교에 사용한다. 입력 기사, 추적 주소 별칭, 이전 분석, 위조 인용을 제외한다. 3건·2개 매체 미만이면 부족 상태를 표시한다. 관점 건수는 SVM 편향 점수로 변환하지 않는다.
- 정치 좌표 표시에 방향 부호를 두 번 적용하던 오류를 수정했다.
- 관점만 대조하는 요청에서 사실 검증 항목의 불필요한 출력 구조를 제거했다. 자동 재시도·예산 증액·공급자 자동 전환은 추가하지 않았다.

## 실제 Chrome 화면 테스트

내장 Browser 도구는 이 대화에서 검색되지 않았다. Playwright CLI로 실제 Chrome 페이지를 열고 http://127.0.0.1:5184/ 에서 링크 입력·전송 동의·분석·자료 대조 버튼을 조작했다. Computer Use 연결이 복구됐다는 의미는 아니다. 화면 캡처와 원문 응답은 로컬 진단 폴더에 보존하고 저장소에 올리지 않는다.

입력: https://www.pressian.com/pages/articles/2026061510494191443

- 제목: 노동계, 최저임금 최초 요구안 1만 2000원…“노동소득으로 살 수 있어야”
- 본문 1,461자. 수정 전에는 취재원의 요구를 작성자 찬성으로 오분류했다.
- 최종 수정 후 공통 명제 “최저임금을 인상해야 한다.”, 작성자 입장 not_expressed, 발화 주체 reported_sources. 인용한 취재원 입장이라는 설명을 화면에서 확인했다.
- 최종 실행 총 21.883초, 본문 취득 1.190초, AI 20.583초, HTTP 200. 단일 사례이며 30초 보장이나 정확도 측정이 아니다.
- 이번 로컬 시험 모델은 명시 선택한 NVIDIA Nemotron Lightning이다. 공식 DeepSeek 키·유료 서비스는 활성화하지 않았다. 생산 기본 모델 변경은 하지 않았다.

비교 기사 직접 연결:

- 데일리안 https://www.dailian.co.kr/news/view/1522509/ : 본문 확보 실패. 근거에 사용하지 않았다.
- 프레시안 https://www.pressian.com/pages/articles/2026061119591835688 : 도급제 노동자 최저임금 적용 부결 기사. 본문 취득 성공.
- 수정 전 관점 전용 요청은 출력 상한에 도달해 약 73.5초 후 실패했다. 정확한 공급자 내부 실패 원인은 관측할 수 없다. 불필요한 사실 검증 출력 구조를 제거한 후 동일 비교 흐름의 AI 대조는 2.237초에 HTTP 200으로 완료됐다. 본문 취득은 1.170초였다.
- 최종 판정은 adds_context. 최저임금 적용 대상과 인상 찬반은 다른 쟁점이므로 반대 입장 기사로 추가하지 않았다. 이 결과로 찬반 추천이 충분히 확보됐다고 주장하지 않는다.

## 아직 미완료인 핵심

실제 SVM 편향 강도는 여전히 산출 대기다. lib/data/stance-model.json은 null이며 실패한 연구 모델을 활성화하지 않았다.

- AI 검토 160건, 명제 관련 102건. 확실한 학습 가능 표본: 찬성 17, 반대 7, 비방향 57.
- AI 라벨 재현 macro-F1 56.6%, 찬성 재현율 16.7%, 반대 50.0%, 사람 평가 0건.
- 반대 표본 부족, 자동 점검 미통과, 학습·모델 배포 이용 검토 대기.
- 기존 3,000건의 이용미승인 상태를 승인으로 바꾸지 않았다. 더 많은 원문이 있다는 사실만으로 학습·공개 권한이나 찬반 정답 라벨이 생기지 않는다.

다음 SVM 작업은 적법하게 학습 가능한 표본 확보, 작성자/취재원 구분을 포함한 입장 라벨 보강, 사건·원본 단위 독립 평가, 기존 통과 기준 충족, 같은 명제 비교 집합 연결 순서다. 검증 기준을 낮추거나 가상 점수를 만들지 않는다.
