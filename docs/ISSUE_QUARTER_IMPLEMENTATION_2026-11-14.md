# 편향 상대 비교 구현 기록 · 2026-11-14

사용자가 제공한 Claude 점검과 `ISSUE_QUARTER_BASELINE_PLAN_2026-11-14.md`에 따라 로컬 구현을 진행했다. 이용 검토 범위는 보류 상태이며 이번 작업에는 공개 배포를 포함하지 않는다.

## 구현한 동작

- 취재원 인용 균형과 기자 서술 방향을 분리했다. 상대 비교의 기본 입력은 취재원 축이다. 화자를 모르는 근거는 양쪽 축의 불확실성에 보수적으로 포함한다.
- 6주제 × 3쟁점에서 기사 단위 주 쟁점 하나를 선택한다. 알려진 명시 명제를 우선하고, 제목·도입부·본문 규칙의 동점 또는 근거 없음은 미확정으로 남긴다. 기존 SVM 쟁점 헤드는 선택 쟁점 대 나머지의 마진 차이로 사용한다. 새 이진 분류기를 학습했다는 뜻은 아니다.
- 찬반 방향 문장 3개 이상이고 좌표 범위 폭이 0.5 이하이면 적격이다. 범위를 중립·중간 점으로 바꾸지 않으며, 단일 숫자 점수도 제공하지 않는다.
- 같은 쟁점·KST 분기 → 반기 → 전체 기간 순으로 집합을 선택한다. 발행일이 없거나 유효하지 않으면 전체 기간만 사용한다. 모델·판정 정책·쟁점 정책·축·정의 버전이 일치해야 한다.
- 매체 동일가중 중앙값을 기준으로 거리/2×100을 계산한다. 범위 입력에는 점수·백분위 범위를 반환한다. 방향은 전체 범위가 기준선 한쪽에 있을 때만 말한다. 백분위는 강도가 아닌 찬반 좌표 순위다.
- 적격 같은 사건 비교가 있으면 먼저 표시하고, 쟁점·기간 비교를 함께 표시한다. 기존 동일 사건 매칭 조건은 바꾸지 않았다.
- 분포에는 매체당 고유 **점좌표** 기사 3건·매체 2곳 이상을 요구한다. 범위 기사는 별도 집계하되 분포의 점 표본 기준을 채우는 데 쓰지 않는다. 이는 범위의 중간 점 대입을 피하기 위한 보수적 조건이다.
- 입력·중복 본문·중복 URL·훈련 원본을 제외한다. 정적 요약 사용 시 별도 서버 전용 본문 해시 목록으로 입력 포함 여부를 확인하며, 포함되면 해당 입력을 빼고 다시 집계해야 한다.
- 분포 파일에는 집계만 담는다. 추천은 로컬 계산 도구로 분리하고, 기본 반환에는 기존 이용 승인 플래그가 필요하다. 화면용 결과에는 제목·URL·매체·날짜·ID만 담는다.
- 운영용 분포와 provenance 파일은 `null`로 유지했다. 연구 후보·벡터·추천 색인을 운영 번들에 넣지 않았다.
