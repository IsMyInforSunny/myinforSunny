# 신뢰 판단 기준 · 2026-11-02

사용자가 말한 “MDC”는 **MBC**로 확인했다. 현재 결과는 사실 주장별로 산출한다.

1. 실제 웹에서 취득한 자료의 공개 URL, 인용 문구와 위치, 발행 시점이 검증된 관측만 사용한다. 가상 예시와 사용자가 붙여 넣은 자료는 출처 가중 집계에서 제외한다.
2. 자료가 주장을 뒷받침하는지, 상충하는지, 자료끼리 충돌하는지 구분한다. 완전히 같은 본문으로 확인된 전재만 한 증거 집단으로 묶는다. 일부 문장을 고친 전재나 본문을 온전히 확인하지 못한 자료는 같은 원본인지 확인하지 못할 수 있다. 매체별 가중치를 해당 매체가 관측한 원본 집단 수로 나누고, 여러 매체가 공유하는 원본은 한 집단으로 한 번만 반영한다. 맥락만 제공하는 자료도 매체의 원본 집단 분모에는 포함한다. 따라서 기사 수가 많은 매체의 영향이 자동으로 커지지 않는다.
3. 출처별 공개 신뢰 응답을 보조 가중치로 적용한다. Reuters Institute의 [Digital News Report 2025 한국 페이지](https://reutersinstitute.politics.ox.ac.uk/digital-news-report/2025/south-korea)에 연결된 [매체별 표](https://datawrapper.dwcdn.net/3sOWE/2/)의 Trust 응답을 100으로 나눈다. 0–10점 중 6–10점을 Trust, 5점을 중립, 0–4점을 불신으로 집계하며, 해당 브랜드를 들어 보지 못한 응답자는 분모에서 제외한다. 따라서 브랜드마다 분모가 다르며 가중치는 인지 응답자의 주관적 인식이다. 믿지 않는 비율을 같은 질문의 별도 점수처럼 다시 더하거나 빼지 않는다. 전체 한국 표본 2,038명은 [보고서 표본표](https://datawrapper.dwcdn.net/vWrbQ/1/)에서 확인했다. [방법론](https://reutersinstitute.politics.ox.ac.uk/digital-news-report/2025/methodology)은 온라인 비확률 표본이고 2%p 이하 차이는 통계적으로 유의할 가능성이 매우 낮다고 명시한다. 작은 가중치 차이를 사실 정확도 우열로 해석하지 않는다.
4. 모든 관측 출처에 비교 가능한 가중치가 있고, 적격 출처가 2곳 이상이며, 독립 증거 집단이 2개 이상일 때만 내부 계산을 수행한다. 독립 증거 집단이 10개 미만이면 비율 대신 집단 수와 표본 부족 안내를 표시한다. 10개 이상일 때도 분모는 기사 수가 아니라 독립 증거 집단 수다. 현재 자동 조사는 주장당 검색어 하나에 최대 2개 자료만 취득하므로 실제 경로에서는 이 10개 비율 기준에 도달할 수 없고 건수만 표시된다. 수집 상한을 늘리려면 검색·모델 예산, 시간, 독립성 검증을 별도로 평가해야 한다. 이는 주장이 참일 확률이나 매체의 종합 신뢰 등급이 아니다.

추가 공개 정보의 취급: 정정·반론 건수는 확정 결과와 전체 보도량 분모 없이 매체별 오류율로 바꾸지 않는다. 매체의 정정 정책이나 소유 정보 공개 여부는 확인 가능한 운영 정보로 기록할 수 있지만 사실 정확도 점수에 임의 비율로 합산하지 않는다. 독립 사실 평가 표본과 비교 가능한 분모가 확보되면 방법 버전을 올려 별도 지표로 평가한다.
