# 기사 링크 입력 분석

기본 입력을 기사 링크로 변경했다. HTTPS 언론사 원문 주소를 넣고 전송 안내를 확인한 뒤 '기사 링크 분석하기'를 누르면, 서버가 공개 본문을 가져와 기존 분석기로 전달한다. 본문 직접 입력은 보조 선택으로 유지하며 가상 예시·선택 글·댓글·명제·자동 조사·팝업·내보내기는 기존 분석 상태에 연결한다.

- API: `POST /api/analyze`의 `kind: url`. 기존 D1 요청 예약·동시 실행·일일/분당 예산 안에서 취득과 분석을 수행한다. 검색 요청이나 새로운 제공자를 추가하지 않는다.
- 기존 운영 허용 호스트의 HTTPS 기사만 취득한다. localhost·IP·인증 정보·포트·미허용 호스트는 차단하고, 기존 취득기의 이동 응답·접근 제한·유료 메타데이터 처리 정책을 유지한다. 포털·단축 링크·로그인 기사 등은 취득에 실패할 수 있다.
- 취득 본문이 없거나 짧으면 모델을 호출하지 않는다. 취득 본문과 댓글에 연락처가 있으면 분석 전에 중단한다. 기사 내용은 기존 모델 지침에 따라 데이터로 처리한다.
- 기존 모델 입력 예산을 유지해 긴 기사는 처음 2,000자 이내를 분석한다. 일부 분석임을 입력 안내와 결과에 표시하고, 원문 주소·제목·분석 글자 수를 결과에 연결한다. 댓글은 자동 수집하지 않는다.
- 링크 변경·입력 방식 변경 시 동의를 초기화하고 이전 분석 결과를 현재 입력과 구분한다. 취소·초기화·후속 요청 이후 도착한 응답은 적용하지 않는다. 원문과 원문 주소는 기존 상세 내보내기 선택 시에만 분석 객체에 포함한다.

검증: 타입 검사, 전체 Vitest 725개 통과·실제 API opt-in 13개 제외, Sites 빌드 통과. URL 분석 검사 12개가 포함된다. 로컬 빌드 서버와 Playwright의 모의 API에서 기본 링크 입력·미동의 요청 차단·링크 요청·원문 표시·부분 분석 안내·주소 변경 후 stale/재동의·초기화·375px 화면을 확인했다. 개발 서버는 시작 중 오류로 종료되어 빌드 서버를 사용했다.

이번 검증에서 실제 외부 모델·검색 호출은 하지 않았다. 모의 UI 성공을 실제 모든 언론사 기사 취득·분석 품질의 보장으로 해석하지 않는다. 기존 Sites 공개 범위와 운영 환경 변수는 변경하지 않는다.
