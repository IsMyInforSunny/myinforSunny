# Groq 무료 파일럿 시험 절차

2026-10-31. 과거 실제 Groq 호출 기록은 존재합니다. 기존 results.json은 부분 실행으로 덮어써져 10사례 전체 통과 증거가 아닙니다. 사람 정답과 대조한 정확도 결과도 아닙니다. 모의 시험과 실제 호출을 구분합니다.

1. 운영자가 계정 자격·청소년 앱 조건·Free 요금제·Data Controls·현재 콘솔 한도를 확인합니다. 이전 확인 기록이나 키 존재만으로 현재 상태를 대신하지 않습니다.
2. 서버에만 Groq 키를 보관합니다. 키를 출력·복사·브라우저 전송·커밋하지 않습니다. 기존 OpenAI 키는 사용하지 않습니다. 모델은 openai/gpt-oss-120b만 허용합니다.
3. 실제 호출은 명시적 파일럿 실행에 한정합니다. 기본 RUN_GROQ_PILOT 비활성을 유지하고 일반 자동 시험에서 키 파일이나 실제 공급자를 사용하지 않습니다. 공개 ENABLE_LIVE_ANALYSIS를 시험 실행만을 위해 켜지 않습니다.
4. 승인된 키 파일 경로를 메모리 환경 변수 GROQ_PILOT_KEY_FILE로 전달하고 RUN_GROQ_PILOT=true일 때만 전용 시험을 실행합니다. 셸 기록에 키 값을 입력하지 않습니다. PILOT_CASES는 분석 사례 필터입니다. 자료 대조에는 number 사례 결과가 필요합니다.
5. 10종 합성 사례의 JSON·인용·해석·실제 토큰·지연을 확인합니다. 자동 재시도·추가 계정·유료 fallback은 금지합니다. 공급자 실패 후 중지하고 원인을 검토합니다. 60초 창과 일일 예산을 다른 운영 트래픽과 공유한다는 점도 확인합니다.
6. 매 실행 요약·실패 코드·모델 출력을 고유 실행 디렉터리로 보존합니다. 최신 요약이 있어도 과거 실행을 덮어쓰지 않습니다. 모델 출력에는 입력 자료가 포함될 수 있으므로 공개·가상 자료만 사용하며 산출물은 Git에서 제외합니다.
7. 24문장·최대 문자수·댓글 5개 입력에서 출력 2,000(추론 포함)과 지연 목표를 확인합니다. 잘린 응답은 실패로 기록하고 재시도하지 않습니다. 필요하면 입력 정책을 조정하되 무료 예약·콘솔 한도를 올리지 않습니다.
8. 독립 평가자 2명의 사람 평가를 완료하고 공개 환경·로그·키 비노출을 확인한 뒤 라이브 공개 여부를 판단합니다. 뉴스는 별도 승인 전 비활성입니다.

요청 예산은 입력·지시문·스키마·래퍼 512·출력 2,000을 합산하며 6,500 초과 시 전송 전 거절합니다. 일일 120,000토큰·500요청은 상한이며 약 2,800토큰/건이면 약 42건입니다. 현재 6,500 예약과 7,000 이동창은 의도된 보수적 보호입니다.
