# 기사 검토 화면·팝업·수집 모듈 업데이트

## 구현 상태

사용자 요청의 화면 축을 **편향 / 자극 / 신뢰**로 통일했다. 공격성은 자극 표현 기준 안에 포함한다. 독립적인 정확도 검증을 마친 편향 점수, 심리 FOMO 지수, 기사 전체의 진실 확률은 제공하지 않는다.

| 기능 | 구현 | 확인 범위 |
|---|---|---|
| 문장 밑줄 | 미대조 사실 주장, 자료와 다름, 자료에서 확인, 표현·FOMO 후보 | 원문 위치 및 자료 인용 검증; 시점 일치 없는 강한 표시는 제외 |
| FOMO 게이지 | 긴급성·희소성·동조 압력의 규칙 기반 후보 문장 수 | 자연 문장 분모; 심리학적 척도가 아님; 문맥 예외가 남음 |
| 기사 비교 지도 | 명시된 제안에 대한 기사별 입장 × 사실 자료 관계 | 실제 취득한 본문과 인용이 있을 때만 채움; 가상 예시는 실제 언론사 점으로 표시하지 않음 |
| 팝업 | `/popup`에서 동일 Workbench 사용, 전체 웹 화면 병행 | 웹 팝업 및 직접 웹 접근 가능; 확장 스토어 배포는 별도 |
| 확장 시제품 | 선택 글 미리보기 후 명시적 전달, 작은 창·전체 탭 | activeTab/scripting만 사용; 2,000자 초과는 차단; 기사 페이지에 자동 주입하지 않음 |
| 로그 | 현재 창 메모리 40건 및 서버 상태 로그 | 원문·자료·검색어·주소·키·원시 오류는 제외 |
| Firecrawl | 선택형 검색과 본문 수집, D1 원자적 무료 크레딧 제한 | 모의 HTTP/D1 시험 통과; 실제 계정·출처 조건·수집 성공률 미확인; 운영 검색은 비활성 |

## 기능별 파일 책임

- `lib/reader-metrics.ts`: 원문 밑줄, 겹치는 인용 분할, FOMO 문장 집계, 기사 비교 좌표.
- `components/article-review.tsx`, `article-map.tsx`: 기사 근거와 좌표 UI. 좌표는 범주형이며 언론사 고정 성향값이 아니다.
- `app/popup/page.tsx`, `components/popup-launcher.tsx`, `extension/*`: 작은 화면과 선택 글 전달.
- `lib/activity-log.ts`, `components/activity-log.tsx`: 브라우저 메모리 로그.
- `lib/server/audit.ts`, `with-audit.ts`: 요청 내용 없이 고정 이벤트·상태·소요 시간·UUID만 기록.
- `lib/server/firecrawl.ts`: 고정 HTTPS API·수집 허용 출처·보수적 크레딧 예약. `docs/FIRECRAWL.md` 참조.
- `lib/server/research.ts`, `research-token.ts`, `verify.ts`: 검색 결과를 증거와 분리하고 서명·인용·시점 대조.

## 자료 선택·신뢰성 기준

1. 검색 결과는 후보일 뿐 사실 확인의 근거가 아니다.
2. 본문은 운영자가 조건을 확인한 정확한 출처만 취득한다. 허용 목록은 진실 인증이 아니다.
3. 제목·출처·발행일·원자료 링크·인용 위치를 확인하고 대상·시점·범위·단위를 대조한다.
4. 시점이 다른 자료는 현재 주장과 상충하는 근거로 승격하지 않는다. 가져올 수 없음은 거짓이 아니다.
5. 도메인 수는 독립 취재원 수가 아니다. 전재·보도자료 공유 여부의 체계적 판별은 후속 과제다.
6. 짧은 인용 일치는 그 인용이 취득 텍스트에 있다는 뜻이며 해석의 정확성·기사 전체의 신뢰성을 보장하지 않는다.

## 후속 과제와 제한

- Firecrawl 키를 서버 secret에 두고 실제 무료 크레딧과 호출 비용·출처 조건을 확인해야 한다. 자동 유료 전환과 결제는 하지 않는다.
- Firecrawl 최종 URL 메타데이터가 없으면 본문을 근거로 채택하지 않는다. 실제 응답과 수집률 검증이 남아 있다.
- 언론사별 고정 편향 지도를 만들려면 기간·주제별 대표 표본, 독립적인 사람 라벨, 좌표 정의 및 평가가 필요하다. 현재 지도는 그 결과를 가장하지 않는다.
- FOMO의 규칙 검출률과 실제 독자 효과는 아직 평가하지 않았다.
- 기사 본문 위에 직접 밑줄을 주입하는 확장 content script와 스토어 배포는 아직 구현 범위 밖이다. 현재 밑줄은 사이트에 입력한 기사에 표시한다.
- Canva 원본 디자인은 브라우저 연결 실패로 열지 못했다. 이번 변경은 사용자 텍스트 요구와 기존 디자인을 기준으로 구현했다.

## 검증

Vitest 전체, TypeScript, 배포 빌드와 Playwright를 사용해 검증한다. 375px에서 기사 표시·팝업·분석 기준 페이지의 가로 넘침과 오류를 확인하며, 데모 대조 결과를 실제 외부 조사 정확도로 주장하지 않는다. 실제 API 호출을 건너뛴 테스트는 별도로 표시한다.
