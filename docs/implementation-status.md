## 구현

- Groq openai/gpt-oss-120b 전용, strict JSON·Zod·원문 인용 검증. 자동 재시도·유료 전환·타 제공자 fallback 없음.
- 서버 전송 동의·연락처 검사. 본문 2,000자, 댓글 5×200자, 총 24문장, 명제 160자, 대조 주장 1개, 자료 2×1,500자. 문자수 안이어도 토큰 예산 초과 시 전송 전 거절.
- D1 원자적 예약: IP별 3회/분·20회/시간, 전체 동시 1개, 60초 합산 7,000토큰, 요청 예약 6,500토큰. 일일 기본 120,000토큰·최대 500요청, 확인된 콘솔 한도의 80% 이하. 429 공유 대기, 사용량 불명 시 예약 유지.
- GPT-OSS harmony 토크나이저로 지시문·입력·스키마·래퍼 512·출력 상한 2,000을 합산. 실제 모델 추론과 응답 길이는 별도 확인 대상.
- 7종 가상 예시, 분모·유보·미대조 표시, 원문 인용, 입력 자료 관계, 출처 없는 다른 관점 제안.
- 뉴스는 승인 플래그·기능 플래그가 모두 필요. 이번 작업에서 활성화하지 않음. URL 자동 취득 없음.

일일 500요청은 처리량 보장이 아닌 상한입니다. 60초 7,000 예산에 다음 요청 6,500을 예약하므로 직전 사용량이 500을 넘으면 다음 요청은 창이 회복될 때까지 대기합니다. 약 2,800토큰/건 기준 일일 약 42건이며 실제 입력에 따라 달라집니다. 이 보호를 처리량 개선 명목으로 완화하지 않습니다.
