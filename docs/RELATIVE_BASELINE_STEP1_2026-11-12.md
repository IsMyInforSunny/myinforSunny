# 상대 기준 1단계 구현 결과 · 2026-11-12

`RELATIVE_BASELINE_PLAN_2026-11-12.md`의 1단계를 구현했다. 기존 검토 완료 스냅샷 3,000건에서 두 규칙 지표의 주제별 분포를 생성하고, 본문 입력 화면과 검토 내보내기에 연결했다.

## 계산 방법

- 입력 기사와 비교 자료 모두 본문 앞 2,000자를 동일하게 사용한다. 기존 본문 분석의 입력 범위와 별개로 상대 비교의 범위를 표시한다.
- `sentence-3.1`로 자연 문장을 나누며 긴 문장의 처리 조각은 한 자연 문장으로 센다.
- `fomo-lexical-1.0`의 자극 표현 후보 검출 문장 비율을 계산한다. 기존 표시 모듈이 쓰던 함수를 `lib/fomo-signals.ts`로 이동하고 원래 모듈에서 다시 내보낸다.
- `cited-sources-0.2`에서 이름 있는 출처가 발견된 자연 문장의 비율을 계산한다. 사실 주장 추출이나 AI 호출을 요구하지 않는다.
- 각 주제에서 매체별 전체 가중치를 동일하게 맞춘 가중 누적 분포를 만들었다. 5%p 간격의 21개 경계와 경계값의 동점 구간을 저장한다.
- 동점은 가중 순위 구간의 가운데 백분위를 표시한다. 같은 값의 비율도 함께 표시한다. 경계 사이 값은 가능한 백분위 범위로 표시한다.
- 기존 여섯 주제 키워드로 입력 주제를 정한다. 가장 많은 키워드가 같은 수로 검출되는 주제는 판단을 보류한다. 제목이 있으면 제목 키워드에 두 배 가중치를 준다.
- 주제 미확인, 기사 100건 미만, 규칙 버전 불일치 상태에서는 상대 위치를 표시하지 않는다.

합계는 3,000건이다. 발행일 범위는 한국 시간 2024-01-01~2026-11-04다. 입력 원문의 SHA-256은 집계 보고서에 기록했다. `relative-baselines.json`과 집계 보고서에는 본문·제목·URL·매체 이름·매체별 점수를 넣지 않았다. 원본 이용 상태와 정치 라벨을 변경하지 않았다.

FOMO 검출 0점의 가중 비중은 주제별 약 98.42~100%다. 이 지표는 값이 같은 기사가 많아 순위만으로 차이를 설명하기 어렵다. 화면은 절대 비율과 건수, 동점 비중을 함께 보여 준다. 규칙 기반 상대 위치를 모델의 표현 판정이나 입장 점수와 합치지 않는다.

## 적용 범위와 남은 작업

이번 단계는 오프라인 규칙 비교와 로컬 제품 연결이다. 공개 배포는 계획서의 사용자 확인 단계에 따라 대기한다. 실시간 분석 엔진 복귀·출력 축소와 공개 링크 허용 호스트의 선행 조건은 이 결과로 완료 처리하지 않는다. 같은 형식 비교와 같은 사건 비교는 각각 2·3단계 작업으로 남아 있다.
