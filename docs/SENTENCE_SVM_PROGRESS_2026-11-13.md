# 문장 SVM 구현 및 실제 기사 검증

현재 상태는 **연구 모델 학습·추론·점수 연결 구현, 생산 모델 비활성**이다. 무오류 모델이나 사이트 전체 기능 완성을 의미하지 않는다. 기존 기사 전체 작성자 입장 모델과 이번 문장 목소리 모델은 별도 과제다.

## 구현한 흐름

1. 실제 기사 본문 앞 2,000 UTF-16자에서 사이트와 동일한 자연 문장 분리를 사용한다.
2. 문장마다 하위 쟁점, 찬성·반대·중립·유보, 기자·취재원·혼합·불명을 분류한다. 사실 발표와 정책 찬성을 구분한다.
3. 고정된 앞뒤 한 문장과 현재 문장 2회로 TF-IDF 입력을 구성한다. 이 설정은 대명사·간접 인용 처리를 위한 것으로, 평가 결과를 보고 여러 설정 중 최고값을 고르는 탐색을 하지 않았다. 모델 설정·학습 코드가 버전에 포함된다.
4. 방향·화자·쟁점 각각의 LinearSVC를 사용한다. 서비스의 margin 차이 0.15 미만 유보를 학습 평가에도 적용한다. 세 분류가 함께 사용 가능한 비율과 유보를 포함한 성능을 기록한다.
5. 검토·배포 기준을 통과한 모델만 서버에서 추론한다. 입력 기사 분석 및 취득한 비교 기사 **전체 본문에서 발췌하기 전** 동일 모델을 적용한다. 모델 가중치는 브라우저로 보내지 않는다.
6. 같은 사건·하위 쟁점·모델 버전만 비교한다. 학습 원본·입력 기사 자체·본문 중복을 제외하고 매체별 고유 3건 이상, 적격 매체 2곳 이상을 유지한다. 사건은 기존 날짜·본문·제목 기반 인덱스의 실제 매칭으로 확인한다. 주제가 같다는 이유만으로 같은 사건으로 취급하지 않는다.
7. 매체 동일가중 중간값과의 좌표 거리/2×100을 상대 점수로 연결했다. 가까운 발언 구성 및 기준선 반대쪽 기사 링크를 별도로 표시한다. 이는 기자의 정치 성향이나 사실의 진실 확률이 아니다. 현재 모델이 비활성이므로 이 생산 흐름이 실제 기사에서 전부 성공했다고 주장하지 않는다.

## 고친 오류

- 쟁점 불명 문장이 미확정 집계에서 빠지는 문제와, 미확정이 있어도 확정 좌표처럼 표시하는 문제를 수정했다.
- 매우 큰 유한 IDF 값이 계산 중 무한대가 되어 특징 없이 절편만으로 분류될 수 있는 수치 오류를 막았다.
- 학습 평가와 서비스의 유보 규칙 차이, 이진 SVM 직렬화의 margin 배율 차이를 평가에 반영했다.
- 같은 반전 쌍을 반복해 독립 10쌍으로 세는 문제를 막았다. 반전 쌍은 양쪽을 모두 맞혀야 정답으로 세며, 언제나 찬성만 출력하는 모델의 개별 정답률 50%로 통과할 수 없다.
- 오래된 분석·조사 계획, 다른 모델, 다른 사건 및 위조된 참고 URL이 비교 집합에 들어가는 것을 차단했다.
- 기준선과 같은 좌표의 입력은 반대쪽 방향을 만들어내지 않으며, 가까운 기사 정렬은 유지한다.
- 캐시 키에 문장 모델 버전을 포함했다. 실패하거나 취소한 일괄 라벨 요청도 예약량을 남겨 재실행으로 작업량 제한이 초기화되지 않도록 했다. 제공자가 토큰 사용량을 반환하지 않으면 실제 사용량은 미확인으로 표시한다.

## 실제 데이터와 결과

- 기존 보관 실제 원전 기사 130건, 2,856문장. 추가 기사 수집이나 유료 API 활성화는 하지 않았다.
- NVIDIA AI 초안 요청 18회에서 17건 완료, 1건은 의미 조합 검증 실패로 검토 대상으로 분리했다. 같은 실패 요청을 자동 재시도하지 않았다. 예약량은 117,000토큰이며 실제 공급자 사용량은 반환되지 않아 미확인이다.
- 초안을 그대로 학습하지 않았다. 실제 기사 17건의 모든 문장을 다시 읽고 검토했으며, 독립 날짜의 반대·수명 연장·지원 쟁점 기사 12건도 추가로 읽었다. 총 29건·643문장의 AI 검토 라벨을 보존했다.
- 그중 학습 가능 582문장: 중립 479, 찬성 40, 반대 63. 유보·화자 불명 등은 학습에서 제외했다. 사람 평가 건수는 0이다.
- 기사·원본·사건·날짜 그룹을 분리한 학습 433문장/평가 149문장, 평가 기사 7건, 그룹 중복 0.
- AI 라벨 재현 macro-F1 0.3758, 찬성 재현율 0, 반대 재현율 0.1111. 화자 macro-F1 0.7241, 쟁점 macro-F1 0.5667.
- 서비스와 같은 유보·세 분류 동시 사용 조건의 macro-F1 0.25, 사용 가능 비율 64.43%. 이는 정확도 통과가 아니다.
- Python과 TypeScript를 실제 기사 130건·2,856문장에서 비교해 문장 ID·방향·화자·쟁점 결과 차이 0건. SVM 추론 중앙값 17.6ms, 95% 지점 24.7ms, 최대 28.1ms. 본문 취득·다른 AI 호출·추가 기사 검색 시간을 포함한 웹사이트 전체 시간은 아니다.
- 최종 집계와 검사 결과는 `docs/test-runs/2026-11-13-sentence-svm/summary.json`에 기록한다. 원문·주소·인용·개별 라벨·연구 가중치는 무시 경로 `.sites-runtime/`에만 보존한다.

## 남은 완료 조건

현재 `lib/data/voice-model.json`은 계속 null이다. 성능 기준 미달, 독립 실제 반전 평가 쌍 부재, 학습·모델 배포 이용 검토 대기를 모두 해결해야 활성화할 수 있다. 미승인 자료를 승인으로 바꾸거나 기준을 낮추지 않았다.

현재 학습은 원자력 세 하위 쟁점부터 진행했다. 나머지 다섯 정책 주제나 일반 뉴스 전체에 대한 SVM 완성을 주장하지 않는다. 찬성·반대 방향을 나타내는 학습 표본과 독립 사건이 더 필요하며, 특히 단순 사실 문장과 의견 문장을 가르는 판별 품질을 개선해야 한다. 추가 데이터에서도 같은 기준을 유지하고 별도로 동결한 실제 기사 평가와 사람 검토를 확보해야 한다.

공개 활성화 전에는 기사 URL 입력 → 본문 취득 → 통과한 SVM → 점수 → 실제 비교 기사 추천까지 브라우저에서 다시 검증해야 한다. 이번 변경에서 공개 배포와 그 전체 흐름의 실제 브라우저 검증은 하지 않았다.
