## 협업

Claude는 문장 분리·본문 배정·분포 컴포넌트·경계 사례와 읽기 검토를 수행했다. Codex는 통합, 보안·예산, 자동 조사, 브라우저·모의·실제 시험과 문서를 수행했다. 동시에 같은 파일을 수정하지 않도록 범위를 나눴다. Claude가 명령·시험을 실행하지 않은 작업을 실제 시험 통과로 설명하지 않는다. 로그인 만료 이후 새 호출이 진행되지 않은 상태를 작업 중이라고 보고하지 않는다.

## 출처 검토에서 드러난 핵심 교훈

검색된 자료, 실제 취득한 자료, 인용이 일치한 자료, 주장을 뒷받침하는 자료, 신뢰할 만한 자료는 서로 다르다. URL 서명과 인용 검사만으로 진실을 인증할 수 없다. 원자료·독립성·대상·시점·단위·정정·사용 조건을 추가해야 한다.

시점이 다른 것을 사실 상충으로 보는 프롬프트와 불충분으로 보는 프롬프트가 함께 있어 정리해야 한다. 신뢰성 집계와 추천 경로가 같은 기준을 사용하도록 해야 한다. 공식기관 자료도 검토 대상 주장에 맞는지 확인해야 하며, 여러 기사가 같은 보도자료를 옮긴 경우 여러 독립 근거로 세면 안 된다.

실제 대조 시험 실패는 숨기지 않는다. 2026-10-31 기준 전체 완료·독립 정확도 평가 완료를 선언하지 않았다. 개발 중지 이후 문서 정리와 요청된 소스 공개 준비는 서비스 활성화를 뜻하지 않는다.
