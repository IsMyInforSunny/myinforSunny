## 작업 6 · 범위 기사를 포함한 비교 집합 (구간 중앙값)

- 각 기사 좌표를 구간 `[lower, upper]`로 다룬다. 점 좌표는 `lower = upper`.
- 적격 기사: 방향 문장 ≥3, `upper − lower ≤ 0.5`(기존 기준 유지).
- 적격 매체: 그 집합에서 적격 기사(점+범위) ≥3건, 매체 ≥2곳(기존 기준 유지).
- 기준선: 하한들의 매체 동일가중 중앙값 `B_low`, 상한들의 매체 동일가중 중앙값 `B_high`. 기준선은 구간 `[B_low, B_high]`.
- 기준선 폭 `B_high − B_low > 0.5`이면 "기준선 불확실"로 표시하고 방향을 말하지 않는다.
- 입력 점수: 입력 구간과 기준선 구간 사이 거리의 최소·최대를 `/2 × 100`으로 낸다. 두 구간이 겹치면 최소는 0. 방향은 입력 구간 전체가 기준선 구간의 한쪽에 있을 때만 말한다.
- 백분위: 입력의 하한·상한 각각의 백분위를 범위로 표시한다.
- 중간점 대입은 어디에서도 하지 않는다.
- 수정 대상: `lib/voice-comparison.ts`, `research/prepare_issue_quarter_coordinates.mjs`, 분포 생성 스크립트, 관련 테스트. `lib/data/issue-quarter-baselines.json`은 로컬 결과로만 생성하고 공개 파일은 `null` 유지.
- 완료 기준: 쟁점×분기·반기·전체별 적격 집합 수를 기록. 경계 사례 테스트(구간 겹침, 기준선 폭 초과, 점만 있는 집합이 기존 결과와 같음).

## 작업 8 · 정제 라벨 재채점·재학습 (사람 대신 두 모델 합의)

1. **평가 세트 재채점:** 기존 고정 평가 문장에 대해 정제 라벨(현재 2,834문장 재검토분)과 원시 라벨의 불일치율을 쟁점별로 기록한다. 기존 후보 모델을 정제 라벨로 다시 채점해 "정제 전/후" 수치를 나란히 기록한다.
2. **합의 정답 세트:** 4개 쟁점에서 기사 30건(약 150문장 이상)을 고른다(찬·반·중, 기자·취재원이 섞이게). Lightning과 Groq `openai/gpt-oss-120b`가 같은 지시문으로 각각 라벨을 붙이고, **두 모델 일치 문장만** 정답으로 쓴다. 일치율을 쟁점별로 기록한다. 이 세트는 학습·임계값 선택에 쓰지 않는다.
3. **학습 라벨 확장:** 4개 쟁점의 보관 기사(작업 5에서 임베딩된 것)에 같은 두 모델로 라벨을 붙여 일치한 문장만 학습에 추가한다. Groq 호출 속도는 위 "사용자 결정"에 적은 실제 계정 한도 기준으로 정하고, 사이트 실시간 분석과 한도를 나눠 쓰는 경우 사이트 몫을 먼저 남긴다. 불일치 문장은 `research/prepare_voice_review_queue.mjs`의 검토 대기열로 보낸다. 출력은 문장 번호와 기호만 받는다.
4. **쟁점 정의 예시:** 쟁점마다 "찬성으로 세는 것 5개 / 세지 않는 것 5개"를 `lib/data/voice-issues.json` 옆 별도 파일로 고정하고 두 모델 지시문에 넣는다. 통계·성과 보도는 중립, 주식 평가액 증가는 소득대체율 찬성이 아님을 포함한다.
5. **재학습:** 확장된 합의 라벨로 쟁점별 방향·화자 SVM을 다시 학습한다. 마진 기준은 학습 데이터 안의 사건 그룹 교차검증으로만 정한다.
6. **확신도 보정:** SVM 마진에 Platt 보정을 적용해 확률을 낸다. 확정 기준을 "보정 확률 ≥0.7"처럼 확률로 정하고 화면 설명에 쓴다.
7. **이중 확인:** 입력 기사 LLM 분석 호출에서 문장별 방향 기호(`s`/`o`/`n`/`u`)를 함께 받는다. SVM과 다르면 그 문장을 미확정으로 두고 구간에 반영한다. 추가 호출은 만들지 않는다.
8. **검사:** 뒤집기(명제 반전), 매체명 가리기, 같은 문장 반복 일치를 매 학습마다 실행해 기록한다.
9. **최종 지표:** 합의 정답 세트 기사 30건에서 "기사 좌표 방향이 합의 정답 방향과 맞는 비율"을 보고한다. 문장 F1과 함께 적고, 둘 다 "AI 합의 기준"으로 표기한다.

- 기존 성능 기준(방향 재현율 ≥0.5, 방향 F1 ≥0.6 등)은 낮추지 않는다. 미달이면 운영 후보로 올리지 않는다.
- 원전 "기준 통과" 표시는 이 작업의 재채점 결과가 나올 때까지 `docs/BIAS_STATUS.md`에서 "재검증 중"으로 바꾼다.
