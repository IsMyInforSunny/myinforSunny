# 내 정보 맑음? — 웹사이트 기술명세 v4.1

2026-10-30. 현재 구현 기준. v4.0의 상충 항목을 대체합니다. 기술명세·개발계획·아키텍처·활동계획서를 같은 범위로 관리합니다.

## 목적과 범위
공개·가상 기사 본문과 댓글을 입력하면 논점 분포 / 자극성 / 근거 충분성의 3축 성분표를 만듭니다. 원문 인용을 클릭해 확인하고, 선택한 사실 주장과 입력 참고자료를 대조하며, AI가 제안한 다른 관점을 구분해 표시합니다. 관련 기사 검색은 사용자 승인 전까지 비활성입니다. 확장 프로그램은 발전 계획입니다. 정치 성향·사람의 성격·진실 확률·편향 점수·평균 점수를 만들거나 게시를 차단하지 않습니다.

## 입력과 API
- POST /api/analyze: demo 또는 text. 본문 2,000자, 댓글 5개×200자, 명제 160자. 본문·댓글 총 24개 분석 문장 구간. 500자를 넘는 구간은 원문 위치를 보존해 나누므로 화면의 문장 수는 분석 구간 수입니다. 초과 시 줄여 달라고 알리며 조용히 자르지 않습니다.
- POST /api/verify: 사실 주장 1개, 참고자료 2개×1,500자. URL은 메타데이터이며 자동으로 읽지 않습니다. 원문 구간과 인용의 일치를 서버에서 재검사합니다.
- GET /api/capabilities: 실제 활성 상태와 한도만 공개하며 키를 반환하지 않습니다.
- POST /api/news: 향후 검색 어댑터. ENABLE_NEWS_SEARCH와 NEWS_TERMS_APPROVED 모두 true이고 DB가 있어야 호출합니다. 현재 둘 다 false입니다. 기사 검색 승인 없이 외부 검색 호출을 하지 않습니다.
- 실시간 요청은 명시적 전송 동의가 필요합니다. 예시 요청은 AI로 전송하지 않습니다. 전화번호·이메일은 최선 노력 방식으로 차단하며 모든 개인정보를 찾는다고 보장하지 않습니다.

## 모델과 데이터 계약
무료 Groq의 openai/gpt-oss-120b 하나만 사용합니다. API 키는 서버 secret. 모델이 JSON을 제안하고 서버가 구조·ID·문장 수·인용·집계를 검증합니다. 표현은 모든 분석 구간에 flagged / clear / undetermined 중 하나를 반환해야 합니다. 누락·중복·위조 인용은 실패 또는 부분 결과로 남깁니다. 자동 보완 호출과 유료 fallback은 없습니다.

사실 주장(factual)은 외부 자료로 확인 가능한 형태라는 뜻이며 참이라는 뜻이 아닙니다. 출처 없는 수치나 전달된 주장도 확인 가능한 명제면 factual입니다. opinion은 가치판단·제안이며 undetermined는 유형 자체가 모호한 경우입니다. 자료가 없으면 미대조, 대조했지만 부족하면 불충분입니다. 인용된 주장도 검토할 명제로 추출할 수 있으며 주장 존재를 확인한 것이 그 명제의 진실을 증명하지 않습니다.

분석 계약 2.1의 부가 필드 counterArguments / searchSuggestions를 추가합니다. 프롬프트 analysis-4.4 / verification-4.2, 예시 demo-curated-2.1, 기준 rubric-4.0. 이전 내보내기 파일의 부가 필드 부재를 허용합니다.

## 수치와 화면
각 축의 건수와 분모·유보 수·미대조 수를 먼저 보여줍니다. MIN_N_FOR_PERCENT=10. 분모 10 미만은 퍼센트와 비율 막대를 표시하지 않고 표본 수를 적습니다. 분모 0은 해당 없음입니다. 논점 다중 배정은 합이 100%를 넘을 수 있으며 전체 여론이 아닙니다. 표현 분류 집계는 공격성 확률이 아닙니다.

헤드라인은 논점 n개 · 검토 표현 m문장 · 대조 전 주장 k개로 생성합니다. 결과 생성 후 결과 영역으로 스크롤하고 포커스를 옮깁니다. 7종 가상 예시를 제공합니다. 기존 6종에 출처에서 확인됨을 추가했으며, 자료가 다른 예시는 본문과 가상 공지 인용을 나란히 표시합니다.

supported는 출처에서 확인됨 · 입력 자료 기준, contradicted는 입력한 출처와 다름입니다. 관계 인용은 sources.text.slice(start,end)와 일치해야 합니다. 인용 일치는 존재만 보장하고 해석의 옳음이나 원 사이트의 일치를 보장하지 않습니다.

## 다른 관점과 기사
AI 제안은 AI 제안 · 출처 없음 배지를 붙이고 대상 claimId·원문 basis·검토할 자료를 표시합니다. 대상 주장이나 basis가 검증되지 않으면 제외합니다. 다른 관점이 없으면 억지 반론을 만들지 않습니다. 출처가 있는 다른 관점은 자료 인용 일치와 링크 검사를 통과한 것만 표시하며 입력 자료 범위를 명시합니다.

관련 기사는 실제 검색 결과의 제목·링크와 짧은 발췌만 사용하고 본문을 복제하지 않습니다. 현재 GDELT 후보 어댑터는 로컬에 준비했으나 실제 서비스 시험에서 429·시간 초과가 발생했고, 약관의 연령·허용 용도·무료 한도 검토와 사용자 승인이 끝나지 않았으므로 활성화하지 않습니다. 검색 후보를 반대 입장이나 사실 근거로 자동 승격하지 않습니다. 이 기능은 목표에 남아 있으나 현재 배포 기능으로 주장하지 않습니다.

## 보호와 운영
사용자가 제공한 실제 Groq 콘솔 한도: 30 RPM / 1,000 RPD / 8,000 TPM / 200,000 TPD. 앱 일일 상한은 min(확인한 콘솔 한도×0.8, 자체 상한)이며 현재 120,000토큰·500회입니다. IP 해시별 3회/분·20회/시간, 전체 활성 1건, 요청당 6,500토큰 예약, 전체 60초 창 7,000토큰 상한을 둡니다. 알려지지 않은 사용량은 예약치를 유지합니다. 429는 공유 대기 상태로 기록하며 다른 제공자로 우회하지 않습니다. 요청 마감은 60초입니다.

운영 계정·청소년 앱 조건은 사용자가 확인했습니다. 키 등록과 실제 호출은 확인됐습니다. 콘솔 수치는 운영자가 제공한 자료에 근거합니다. 실시간 활성 상태는 /api/capabilities를 따르며 독립 정확도 평가 전에는 실험 기능으로 표시합니다. 유료는 FREE_ONLY=true / ENABLE_PAID_PROVIDER=false / PAID_ACTIVATION_CONFIRMED=false입니다.

입력·결과를 제품의 분석 기록으로 저장하지 않습니다. D1에는 요청 ID, IP의 해시, 시간, 토큰 예약·정산·대기 상태만 저장하고 2일 뒤 정리합니다. IP 원문·본문·자료는 저장하지 않습니다. 사용자 수동 JSON 내보내기만 있습니다. 제공자 보관 정책은 별도입니다. 서버 코드의 요청 본문·공급자 원문 로그 금지, 플랫폼 로그의 별도 점검, 산출물 비밀키 검사를 출시 검증에 포함합니다.

## 평가
가상 학교생활 자료 40개와 독립 평가자 2명의 빈 CSV, 비교 스크립트를 준비했습니다. 사람이 작성한 정답으로 표시하지 않습니다. 과제별 표본 수·일치도·Cohen kappa·합의 라벨 대비 모델 일치를 나누어 보고합니다. 현재 사람 평가는 미실시입니다. v4.0의 동결 60문장·자료 관계 20쌍 및 목표 macro-F1은 별도 후속 기준이며 달성했다고 주장하지 않습니다. PCA·SVM은 선택 연구로서 기본 분석의 선행 단계가 아닙니다.

## 2026-10-31 최종 검증 보완
정상 문장은 clearSentenceIds로 짧게 받아 서버에서 clear 결과로 복원합니다. 나머지 문장 객체와 합쳐 누락·중복을 검사하며 모든 최종 문장 수는 유지합니다. 모델 입력에서 원문과 문장 본문을 중복 전송하지 않습니다. 24문장 실제 시험에서 이 형식으로 성공했고 출력 2,000·예약 6,500 제한은 유지했습니다. IP 식별자는 서버 HMAC으로 보호하며 원 IP를 기록하지 않습니다. 참고자료 본문이 없는 대조는 동의·개인정보·원문·활성 상태 검사를 유지하면서 토큰 예약과 공급자 호출을 하지 않습니다.

자료 대조 v4.2는 참고자료 문장 ID만 모델이 선택하고, 서버가 해당 자료에서 인용과 위치를 복원합니다. 입력 기사에서 참고자료 인용을 만들어낼 수 없도록 경계를 강화했습니다. 본문만 있는 기사도 논점을 추출하고 명시적 사실·제안을 구분하도록 분석 지시를 보완했습니다. 실시간은 실험 기능이며 독립 정확도 수치는 미평가입니다.

논점·다른 관점의 검토를 빈 배열로 생략하지 않도록 후보 또는 명시적 해당 없음 응답을 요구합니다. 해당 없음은 화면의 논점·반론 건수로 올리지 않으며, 논점 불명확은 부분 결과로 남깁니다. 이 장치도 의미 정확성을 보장하지 않습니다.
