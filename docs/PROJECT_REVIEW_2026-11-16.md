## 2. 문제점

### 2-1. 편향 모델이 막힌 진짜 이유: 믿을 수 있는 라벨이 없다
- 라벨을 **Codex 한 모델이 한 번씩** 붙였다. 원시 라벨과 재검토 라벨이 76.5% 다르다.
- 합의 라벨을 만들려던 `review-a`·`review-b`는 **서로 다른 기사**를 검토한 것이어서 겹치는 문장이 0개다(Claude가 독립 검토 두 벌이라고 잘못 가정했다). 두 벌 모두 같은 Codex 검토다.
- 그래서 재채점·재학습이 입력이 없어 멈췄고, 현재 좌표는 검증되지 않은 모델에서 나온다.
- 라벨링을 Codex(GPT 사용량)로 해서 사용량 한도에 걸려 중단됐다.

### 2-2. 연구 빌드가 시작되지 않는다
`start:research`가 Vite 개발 서버 초기화에서 `Unexpected token 'E'` JSON 오류로 실패한다. 11-05부터 기록된 Windows 개발 서버 문제와 같다. 11-16 새벽에 점수가 나왔던 방식은 **빌드 후 Wrangler로 실행**(`local-demo-build-20261116`)이었다. 시연 경로가 재현되지 않는 상태다.

### 2-3. 점수가 나와도 변별이 약하다
판별률(방향이 정해지는 비율)이 의대 55.8%, 최저임금 52.9%, 원전 33.3%다. 방향 문장 ≥3인 기사 중 절반 이상이 구간 폭 조건에서 탈락한다. 주택 공급은 비교가 성립하지 않는다.

### 2-4. 링크 분석 범위
- 조선·중앙·한겨레·경향(AI 수집 제한), 네이버(robots 전체 차단)는 서버로 가져올 수 없다. C2를 구현해도 이 매체들은 그대로 안 된다.
- C2는 DNS 재바인딩 우려로 멈췄고 배포 런타임 실측은 아직 안 했다.

### 2-5. 저장·배포 상태
- 수정 파일 15개가 커밋되지 않았고, 커밋 1개가 GitHub에 올라가지 않았다.
- 공개 사이트는 11-14 버전(44)이다. 속도 개선·실패 안내·추출 개선이 빠져 있다.

## 5. 해결 방법

### 5-1. 라벨을 두 모델로 다시, NVIDIA에서 (편향의 유일한 길)
- NVIDIA에서 쓸 수 있는 **계열이 다른 모델 2개**(Lightning + 다른 계열 1개)가 같은 기사·같은 문장에 라벨을 붙인다. 출력은 문장 번호와 기호만. 토큰 한도가 없으므로 20초 간격으로 밤새 돌린다.
- 범위: 의대·최저임금·원전 3개 쟁점, 쟁점당 평가 30건 + 학습 120건 = 450건 × 2모델 = 900회, 약 5시간.
- 두 모델이 일치한 문장만 사용. 일치율을 쟁점별로 공개한다.
- Codex는 라벨을 직접 붙이지 않고 스크립트만 돌린다.

### 5-2. 기한을 정한 두 갈래
- **11-19까지** 재학습 후보가 게이트(방향 F1 ≥0.6, 찬·반 재현율 ≥0.5)를 통과하면 SVM 좌표로 간다.
- 통과하지 못하면 **"AI 문장 분류 기준 인용 균형"**으로 편향 칸을 채운다. 분석 때 LLM이 문장별 찬·반·중립과 화자를 답하고(코드에 `method:'ai'` 경로와 지시문이 이미 있다), 같은 식 `(S−O)/(S+O)`과 같은 상대 기준을 쓴다. SVM은 "연구 중인 검증 모델"로 방법 페이지에 적는다. 이 전환은 사용자 결정이다.

### 5-3. 연구 빌드 고정
`start:research`를 Vite 개발 서버가 아니라 **빌드 → Wrangler 실행** 방식으로 바꾼다(11-16 새벽에 동작한 방식). 30분 작업이다.

### 5-4. 링크 범위: C2 대신 "목록 확대 + 이 기사 분석 버튼"을 권한다
- C2는 보안 장치가 많이 필요한데, 사람들이 가장 많이 가져올 네이버·조선·중앙 링크는 여전히 안 된다. 들이는 시간에 비해 얻는 범위가 작다.
- **C1:** AI 접근을 막지 않는 매체 20~30곳을 확인해 등록(하루).
- **A:** 북마클릿 "이 기사 분석"으로 사용자가 보고 있는 화면의 본문을 보낸다. 네이버·조선도 되고 계획서의 확장 프로그램 구상과 같다(하루).
- C2를 계속하려면 먼저 배포 런타임 실측 30분으로 가능 여부만 판정한다.

### 5-5. 지금 되는 것부터 공개
속도 개선, 실패 안내, 추출 개선은 자료 이용 문제와 무관하다. 커밋 → GitHub → 공개 배포. 편향 칸에는 "이 기사는 찬반 문장이 n개" 같은 이미 계산되는 설명을 먼저 보여 준다.
