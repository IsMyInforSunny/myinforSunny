# Codex 작업 지시 · 병렬 회차 · 2026-11-16

먼저 `docs/WORK_RULES.md`를 읽고 그 방식으로 진행한다. 루트 `AGENTS.md`에 `WORK_RULES.md`를 가리키는 한 줄을 추가한다. 이번 회차는 세 레인을 **동시에** 진행하고, 통합 담당(주 에이전트)이 마지막에 합친다.

## 지난 회차에서 멈춘 것에 대한 판단

- C2를 "DNS 확인 뒤 연결 IP를 고정할 수단이 없다"는 이유로 통째로 보류했다. 우려는 타당하지만, **실제 위험이 있는지 확인하지 않고 멈췄고**, 그와 무관한 AMP·다음 포털 추출기·전체 테스트·빌드·커밋까지 함께 보류했다. 규칙 1에 따라 이번에는 사실 확인부터 한다.
- DNS 재바인딩이 위험한 이유는 서버가 **자기 내부망**에 접속할 수 있을 때다. 배포 환경(Workers 계열)이 사설·루프백 주소로 나가는 연결을 원래 막는다면 이 위험은 배포 환경에서 성립하지 않는다. 이 점을 아래 레인 B의 첫 단계에서 실측한다.

## 레인 B · 링크·추출 (보조 에이전트 1)

수정 범위: `lib/server/retrieval*.ts`, `lib/server/open-retrieval.ts`(신규), `lib/server/article-*.ts`, `lib/data/fetch-denylist.json`(신규), 해당 테스트, `scripts/check-open-fetch.mjs`.

1. **사실 확인(30분 이내):** 배포와 같은 런타임(가능하면 비공개 미리보기 배포, 아니면 `wrangler dev --remote`에 준하는 방식)에서 아래 주소로 `fetch`가 되는지 확인하고 상태·오류만 기록한다. 응답 본문은 저장하지 않는다.
   - `https://127.0.0.1/`, `https://10.0.0.1/`, `https://192.168.0.1/`, `https://169.254.169.254/`, `https://[::1]/`
   - 로컬 `wrangler dev`(내 PC)에서도 같은 확인을 해 차이를 기록한다.
2. **결과에 따른 진행:**
   - **배포 런타임이 전부 막으면:** C2를 구현한다. 방어는 여러 겹으로 둔다.
     - 요청 전 목적지 검사(`CODEX_COMMAND_2026-11-16C.md` 3-1 전부) + DoH로 A·AAAA 확인. 요청 직후 한 번 더 조회해 결과가 사설로 바뀌었으면 응답을 버린다.
     - 응답을 그대로 돌려주지 않는다. `text/html`이고 기사 추출이 300자 이상 성공한 **추출 본문만** 사용한다. 헤더·원문 HTML·오류 본문은 사용자에게 가지 않는다.
     - 쿠키·인증 헤더 없음, 이동은 같은 등록 도메인만, 요청 3회·5초·2MB 제한.
     - `ENABLE_OPEN_FETCH`는 **배포 환경에서만** 켤 수 있게 하고, 로컬 실행에서는 `ALLOW_LOCAL_OPEN_FETCH=true`를 추가로 요구한다(로컬 PC는 내부망에 닿기 때문).
     - robots·AI 제한·거부 목록·호스트별 속도 제한·음성 캐시(3-2, 3-3, 3-4) 그대로.
   - **배포 런타임이 하나라도 통과시키면:** C2는 구현하지 않고 멈춘다. 대신 **C1(허용 목록 확대)**로 전환해 이번 회차에 끝낸다: 11-05 조사에서 접근이 허용된 매체부터 robots와 추출을 확인해 20곳 이상 등록한다. 사용자에게는 "배포 환경이 내부 주소 연결을 막지 않아 C2는 위험하다. C1로 진행했다"고 한 줄 보고한다.
3. **C2와 무관하게 이번 회차에 끝낼 것:** 같은 등록 도메인 AMP 가져오기, 다음 포털(`v.daum.net`, robots 404=허용) 전용 추출과 원 언론사 표시, 네이버는 `ROBOTS_DISALLOWED` 안내, 거부 목록 파일.
4. `check:links`로 실제 점검(허용 목록 밖 10 + 거부 3 + 포털 2). 결과는 `docs/test-runs/open-fetch-2026-11-16.json`.

완료 기준: 위 2의 어느 쪽이든 결론이 나고, 3·4가 끝나고, `check:quick` 통과, 레인 커밋 1개.
