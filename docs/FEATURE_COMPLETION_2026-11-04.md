# 분석 기능 구현 보완 기록

## 편향 점수가 나오지 않았던 이유

기존 구현은 학습·추론 코드와 화면을 연결했지만 실제 학습 자료와 검토된 모델 파일을 확보하지 못했다. 생산용 `lib/data/bias-model.json`은 여전히 `null`이다. 코드 연결을 실제 모델 학습 완료로 취급하면 안 된다.

추가로 두 가지 구현 제약을 수정했다.

- 단일 주제 모델은 그 명제와 입력이 정확히 같아야 했다. 이제 여러 주제로 학습하고 별도 주제로 평가한 `topicScope: cross_topic` 모델을 지원한다. 학습 주제 최소 3개·평가 주제 최소 2개, 매체마다 양쪽에 최소 2개 주제와 3개 독립 기사, 주제와 원본 집단의 분리를 검사한다. 단일 주제 모델의 범위 제한은 유지한다.
- 한 번의 대조는 기사 2개만 처리하므로 한 주제에서 매체별 기사 3개를 모으기 어려웠다. 적격 모델이 있는 경우 한 계획 호출에서 해당 비교 대상에 서로 다른 검색어 3개를 만들고, 이미 취득한 URL을 제외해 조사 묶음을 모은다. 같은 서명 계획의 유효 인용만 합산하며 새 조사 계획은 이전 계획을 대체한다. 매체별 3개·2개 매체 기준, 취소, 무료 예산과 61초 모델 호출 간격은 유지한다.

공식 K-News-Stance 자료를 가져왔을 때 `fetchedAt=null`인 이유로 학습 준비가 불가능하던 문제도 수정했다. 실제 `importedAt`과 공식 데이터 출처를 기록하고, 원 사이트에서 취득한 시각으로 위장하지 않는다. 사용 조건·원본 집단·주제·사람 검토는 자동 승인하지 않는다.

## 검색과 본문 취득

GDELT·Firecrawl·Tavily에서 Cloudflare Workers가 지원하지 않는 `redirect: error`를 제거했다. `manual`로 요청하고 3xx는 따라가지 않는다. GDELT의 제한·잘못된 검색어·시간 초과·서비스 응답 실패를 구분한다. 오류 객체를 빈 검색 결과로 바꾸지 않는다.

GDELT 자동 검색어는 기존 계획/분석 호출 안에서 영문 번역 색인에 맞춘 핵심어로 생성한다. 한국어 검색 제공자는 기존 한국어 검색어를 유지한다. 설명과 화면 라벨은 한국어다. 별도 번역 호출이나 추론 재시도는 추가하지 않았다.

여러 semantic article이 있는 페이지에서는 짧은 카드 대신 가장 긴 본문 하나를 선택한다. 접근 제한 표시, 허용 호스트, 취득 크기와 원문 인용 검사를 유지한다.

## 남은 외부 입력

- 실제 학습 데이터와 기사별 출처·원본 집단·사용 조건 검토. 공식 자료 신청: https://form.jotform.com/252588865320465
- 학습한 정확한 모델 버전에 대한 실제 독립 평가자 2명의 원본 40개 축 검토. 합성 시험을 사람 평가나 실제 모델 성능으로 보고하지 않는다.
- Firecrawl은 CLI 미인증 상태에서 브라우저 인증을 요청했다. 인증 완료 전 사이트용 키나 무료 잔여 크레딧을 확보했다고 주장하지 않는다.

## 검증

수정 후 TypeScript 검사와 빌드가 통과했다. 사이트 자동 시험 755개 통과·13개 건너뜀, Python 학습 절차 시험 13개와 자료 준비 시험 16개가 통과했다. 이는 합성 입력에 대한 구현 검사이며 실제 기사 모델 정확도·사람 검토·실제 Groq 호출 성공을 뜻하지 않는다.
