# 2026-11-02 후속 웹사이트 품질 점검

Canva 중심 메인과 편향·자극·신뢰 축을 유지하며, 중단됐던 동일 본문 집계 변경을 검증하고 실제로 재현된 상태·본문 처리 오류를 보완했다. 이 기록은 로컬 구현과 공개 합성 자료 검증에 해당한다.

| 요구사항 | 이번 확인 범위 |
| --- | --- |

## 수정한 동작

- **본문 중복:** 서버가 발췌 전에 만든 본문 해시·취득 길이·잘림·추출 버전을 서명한 자료에 보존한다. 같은 매체·명제의 URL 별칭과 동일 본문 묶음은 한 기사로 센다. 인용문만 같거나 본문이 잘린 자료는 동일 본문으로 확정하지 않는다. 다른 매체의 동일 내용은 독립 근거라는 뜻이 아니다.
- **예시 요청 후처리:** 취소·초기화·새 요청 뒤 이전 예시가 좌표창을 다시 여는 경로를 막았다. 정상 완료 때의 좌표 이동은 유지했다.
- **내보내기:** 메인 게이지와 같은 수동·현재 외부 조사 집계 순서로 완료 건수를 계산한다. 늦은 실패·건너뜀도 같은 기준으로 반영한다. 기본 파일에는 원문·참고자료 상세를 넣지 않는다.
- **추천 중복:** 추적 주소·www·fragment와 명제 공백 차이 때문에 같은 기사의 이전 반대 입장과 최신 분류가 각각 추천되는 문제를 보완했다. 최신 인용이 유효하지 않으면 예전 분류를 되살리지 않는다. 원문 링크는 확인한 주소를 유지한다.
- **본문 추출:** 정확한 article·main 태그만 본문 후보로 삼고, 중첩된 광고·메뉴 제외 영역 전체를 제거한다. 일반 텍스트 안의 meta 예시는 해독 설정으로 쓰지 않는다. 본문 8,000자·제목 250자 경계에서 이모지의 UTF-16 쌍을 자르지 않는다. 전체 길이와 추출 버전을 보존하며 기존 크기·호스트·리다이렉트 제한은 유지한다.
- **안내:** 수동 URL 대조에는 본문을 직접 넣어야 함을 설명한다. 분석 기준 페이지의 매체 좌표 축·표본·공식을 실제 화면과 맞추고, 자극의 본문·댓글 분모와 FOMO의 본문 전용 분모를 구분한다. 제품 README와 기술명세의 오래된 상태를 갱신했다.
- **분할 경계·부분 결과:** 긴 문장의 처리 경계를 가로지르는 FOMO 표현도 각 구간의 유효한 원문 위치에 밑줄과 전체 표현 설명을 제공한다. 자연 문장 분모와 탐지 건수는 늘리지 않는다. 공백만 있는 참고자료 인용은 밑줄·좌표 근거로 쓰지 않는다. 모델이 알 수 없는 댓글 논점 ID나 존재하지 않는 문장의 상세 표현을 만들면 제외 사실을 부분 결과 경고로 남긴다.

## 검증 범위

서명된 계획→모의 기사 취득→서명 자료 대조→관측 추출→집계→좌표 렌더를 연결했다. 동일 본문 3주소는 기사 1개·중복 주소 2개로 세어 기준선을 기다린다. 같은 인용에 서로 다른 전체 본문을 가진 기사는 구분한다. 브라우저 응답 객체를 변조해도 서명된 취득 정보만 사용한다.

브라우저에서 예시 취소·초기화·정상 완료, 조사 취소·새 동의·명시적 재시작·입력 변경/복원·한도 안내, 현재 자료의 추천·좌표 연결, 원문 인용·팝업 키보드 조작·모바일 넘침을 확인했다. 기본·상세 JSON을 실제 다운로드해 미리보기와 비교했다. 분석 기준 페이지는 375·768·1280px에서 가로 넘침이 없었다. 재현 절차는 [브라우저 검사 안내](../scripts/browser-qa/README.md)를 따른다.

검사 중 발견한 모의 응답 설정 누수와 전역 오류 안내의 중복 선택은 검사 스크립트에서 수정했다. 화면 준비 전에 버튼을 누르지 않도록 capabilities 응답을 기다린다. 이 실패를 제품 검사 통과로 기록하지 않았다.

타입 검사·웹사이트 회귀 **383개**·빌드가 통과했다. 실제 API opt-in 시험 13개는 건너뛰었다. 최종 기록: [통합 검증](test-runs/2026-11-02T08-00-46-509Z-website/results.json). [이전 381개 통합 검사와 브라우저 기록](test-runs/2026-11-02T07-51-16-068Z-website/browser.json)도 보존한다. 로컬 `/`, `/analyze`, `/popup`, `/methodology`는 200이며 live·webSearch·webFetch=false, 비활성 실시간 요청 503, 로컬 비공개 설정 접근 403을 확인했다.

독립 코드 검토에서 새 중첩 제외 처리기가 생략된 HTML `</head>` 뒤의 실제 본문을 버리는 회귀를 발견했다. 명백한 body·article·main 시작에서만 head의 암묵적 닫기를 인정하도록 수정했고, 속성 인용문 속 가짜 태그와 미닫힌 광고 영역을 함께 검증했다. 이 수정 후 전체 검사를 다시 실행한 결과가 위 383개 기록이다.

FOMO 경계 브라우저 검증은 자연 문장 1개·처리 단위 2개·표현 후보 문장 1개에 밑줄 2부분과 동일한 전체 표현 설명이 연결되는지 확인했다. 원문 문자열을 보존하며 375px 가로 넘침이 없었다.

## 남은 실제 검증

실제 출처별 본문 추출·발행일·인용 맥락·모델 입장 분류 정확도, 공급자의 현재 무료 조건·잔여량·출처 이용 조건과 실서비스 안정성은 미확인이다. 독립 평가자 2명의 40사례 평가와 PCA/SVM 실측 성능, 공개 배포·운영 검증도 남아 있다. 휴리스틱 본문 추출과 자동 회귀 통과만으로 기사 정확도나 서비스 완성을 주장하지 않는다.
