# 중립 방향과 쟁점·화자 유보 분리

편향 기능의 기사 집계 결함을 수정하기 위한 명시적 실험 계약을 구현했다. 운영 모델을 활성화하거나 새 계약을 승인한 변경은 아니다.

## 변경

- `decisionPolicy: voice-neutral-independent-1.0`을 지정한 문서는 확정 중립을 유지하고 방향·쟁점·화자의 불확실성을 별도로 집계한다.
- 정책이 없는 기존 문서와 운영 모델은 기존 공동 확정 의미를 유지한다. 미지원 정책은 거절한다.
- 찬반 문장은 여전히 쟁점과 화자를 모두 확정해야 좌표에 기여한다. 누락·중복·잘못된 쟁점을 중립으로 채우지 않는다.
- 확정 중립의 쟁점·화자 유보는 찬반 좌표의 미확정 수에 더하지 않는다. 중립만 있는 기사는 0점으로 만들지 않는다.
- 같은 모델 버전이라도 집계 정책이 다른 기사 좌표는 비교하지 않는다. 입력 좌표 역시 문서의 집계 정책과 같아야 한다.
- 집계 상세 화면에 세 종류의 미확정 수를 표시한다. 실험 검사는 기존 기사별 검사 스크립트의 `--neutral-independent` 옵션으로 실행한다.

## 실제 기사 검사

보관된 고정 평가 기사 7건에 기존 후보 가중치·기존 벡터·마진 0.15를 그대로 적용했다. API 호출은 0회다. 이전 보고서를 덮어쓰지 않고 별도 로컬 보고서 `heldout-independent-neutral.local.json`에 기록했다.

| 항목 | 기존 계약 | 실험 계약 |
|---|---:|---:|
| 평가 기사 | 7 | 7 |
| 모든 비광고 문장의 벡터 확보 | 6 | 6 |
| 좌표에 영향을 주는 미확정이 없는 기사 | 0 | 2 |
| 일부 쟁점의 관측 좌표가 있는 기사 | 2 | 2 |
| 기존 기준의 대표 좌표 산출 가능 기사 | 0 | 0 |

미확정이 사라진 두 기사는 방향 문장이 없어 대표 좌표를 산출하지 않는다. 찬반 문장이 있는 기사에는 실제 유보가 남아 있다. 하나의 문장은 학습 파티션과 동일한 정규화 텍스트여서 평가 벡터 재사용에서 제외했다. 이번 결과는 이미 관찰한 고정 평가 집합의 회귀 진단이며 새로운 독립 정확도나 완성 증거가 아니다.

## 운영 상태와 남은 작업

배포 `/api/capabilities` 확인: HTTP 200, `biasModel.ready=false`, 주제 목록은 비어 있다. 연구 계약은 release 스키마/평가 재현과 독립 기사 검증을 마치기 전 운영 경로에 연결하지 않는다. 기존 연구 원본의 이용 검토가 미완료이고, 같은 사건·매체별 3건·2개 매체의 비교 표본도 부족하다. 운영 아티팩트는 계속 null이다. 승인 값·성능 수치·비교 표본을 임의로 만들지 않았다.

사용자가 창을 다시 연 후에도 Browser 선택은 `Browser is not available: iab`, 연결 목록은 `[]`였다. 화면 조작이나 실제 기사 입력 UI 검사는 수행하지 못했다. 다른 브라우저로 대체하지 않았다.

다음 구현은 문맥을 이용한 방향·쟁점·화자 분류 개선, 이용 근거가 확인된 학습/독립 평가 자료 확보, 새 집계 계약의 release 재현, 같은 사건의 다매체 표본 확보 순서다. 현재 결과를 배포 편향 기능 완성으로 보고하지 않는다.

## 검증

- `npm run typecheck`: 통과.
- `npm test`: 994개 통과, 13개 건너뜀.
- `npm run build`: 통과. 기존 의존성 eval 및 Node 폐기 예정 경고가 있다.
- `git diff --check`: 통과.

원문·벡터·라벨·키는 커밋하지 않는다. 집계 계약과 검증 도구만 저장하며, 운영 모델 미완성 상태에서 이번 연구 변경을 추가 공개 배포하지 않았다.

## 후속: 모델 평가·release·서버 계약 연결

모델 평가 CLI에 `--decision-policy voice-neutral-independent-1.0`을 추가했다. 원래 세 헤드 공동 확정 성능과 분모는 유지하고, 독립 중립 방향의 분류 가능 수·macro-F1·찬반 재현율을 별도로 기록한다. 새 성능이 기존 성능을 덮어쓰지 않는다.

release 재현은 후보의 정책을 평가 CLI에 전달하고, 수치 기준과 분모 일관성을 확인한 뒤에만 `sentence-voice-embedding-svm-1.1` 및 정책을 아티팩트에 넣는다. 기존 1.0 아티팩트는 기존 정책만 허용한다. 서버 파서는 아티팩트·평가 설정·실측 방향 통계의 정책 일치를 검사한다. 서버 추론은 검증된 정책을 문서에 전달하고 캐시 식별자에도 포함한다. 이용 승인 검사는 유지하며 실제 운영 아티팩트는 계속 null이다.

기존 보관 평가 149문장 회귀 재검사(API 0회, 별도 후보/보고서 저장):

| 항목 | 기존 공동 확정 | 새 방향 판단 |
|---|---:|---:|
| 판단 가능 문장 | 115/149 | 140/149 |
| 방향 macro-F1 | 0.7696 | 0.8102 |
| 찬성 재현율 | 0.75 | 0.75 |
| 반대 재현율 | 0.8889 | 0.8889 |

이 수치는 AI 교사 라벨과의 일치이며 사람 정확도가 아니다. 이미 사용한 평가 자료의 회귀 결과여서 새 독립 평가로 계산하지 않는다. 운영 승인 또는 기사 상대 점수 완성의 증거가 아니다.

후속 검증: 타입 검사·빌드 통과, JS 테스트 996개 통과·13개 건너뜀, Python 관련 테스트 34개 및 하위 검사 24개 통과, diff 검사 통과. Browser는 계속 `iab` 미가용·목록 빈 상태다. computer-use 도구 검색에서도 화면 제어/활성화 도구가 제공되지 않았다. 배포 capabilities는 HTTP 200·`biasModel.ready=false`이며 새 공개 배포는 수행하지 않았다.

## 후속: 문맥 분류 개발

`research/crossvalidate_voice_context.py`를 추가했다. 실제 학습 218문장·사건 그룹 5분할 안에서만 비교하며 외부 평가·반전 쌍 라벨/벡터는 사용하지 않는다. C=1·마진 0.15를 유지하고 API를 호출하지 않는다. 실제 기사 문장 식별자를 확인하며, 이웃 벡터는 동일 학습 기사의 해당 문장에 연결된 것만 사용한다. 없는 이웃 벡터는 0 블록과 부재 표시로 기록한다. TF-IDF는 각 학습 fold 안에서만 어휘/IDF를 학습한다.

| 구성 | 방향 macro-F1 | 판단 가능 / 218 | 방향 문장 수 | 쟁점 오류 | 화자 오류 |
|---|---:|---:|---:|---:|---:|
| 현재 문장 의미 벡터 | 0.6039 | 168 | 73 | 13 | 5 |
| 앞뒤 의미 벡터 결합 | 0.5897 | 172 | 75 | 13 | 6 |
| 앞뒤 원문의 글자 특징 결합 | 0.6473 | 174 | 76 | 15 | 4 |
| 방향·화자에만 글자 문맥 결합 | 0.6229 | 174 | 76 | 14 | 4 |

이웃 의미 벡터는 앞 문장 78개·뒤 문장 78개만 확보되어 있고 280개 슬롯이 없다. 이 방식은 성능이 낮아 채택하지 않는다. 글자 문맥 결합은 방향 지표가 개선되지만 쟁점 오류가 늘어난다. 모두 학습 개발 수치이며 독립 정확도나 운영 점수 완성으로 취급하지 않는다. 추가 독립 자료와 기사 단위 검증 없이 배포하지 않았다.

검증: Python 관련 37개 테스트·하위 검사 24개 통과, diff 검사 통과. 이번에는 Python 연구 도구와 문서만 변경했으므로 앞서 통과한 웹 996개·타입·빌드를 반복하지 않았다. 이전 원본·평가 보고서는 보존했다. 새 runtime 보고서는 `context-group-cv.local.json`, `context-lexical-group-cv.local.json`, `context-heads-group-cv.local.json`이며 Git에는 포함하지 않는다. 마지막 보고서의 모드 결과는 위 표와 같으며 이후 추가한 설명 필드는 도구 코드에 명시되어 있다.

사용자 재연결 후 Browser를 다시 선택했으나 `Browser is not available: iab`, 연결 목록 `[]`였다. 화면 조작은 미수행이다. 배포 capabilities HTTP 200·편향 모델 비활성도 다시 확인했다. 남은 필수 작업은 이용 근거가 확인된 자료, 독립 기사 단위 검증, 같은 사건 비교 집합 확보와 실제 Browser 연결이다.
