# 중립 방향과 쟁점·화자 유보 분리

편향 기능의 기사 집계 결함을 수정하기 위한 명시적 실험 계약을 구현했다. 운영 모델을 활성화하거나 새 계약을 승인한 변경은 아니다.

## 변경

- `decisionPolicy: voice-neutral-independent-1.0`을 지정한 문서는 확정 중립을 유지하고 방향·쟁점·화자의 불확실성을 별도로 집계한다.
- 정책이 없는 기존 문서와 운영 모델은 기존 공동 확정 의미를 유지한다. 미지원 정책은 거절한다.
- 찬반 문장은 여전히 쟁점과 화자를 모두 확정해야 좌표에 기여한다. 누락·중복·잘못된 쟁점을 중립으로 채우지 않는다.
- 확정 중립의 쟁점·화자 유보는 찬반 좌표의 미확정 수에 더하지 않는다. 중립만 있는 기사는 0점으로 만들지 않는다.
- 같은 모델 버전이라도 집계 정책이 다른 기사 좌표는 비교하지 않는다. 입력 좌표 역시 문서의 집계 정책과 같아야 한다.
- 집계 상세 화면에 세 종류의 미확정 수를 표시한다. 실험 검사는 기존 기사별 검사 스크립트의 `--neutral-independent` 옵션으로 실행한다.

## 실제 기사 검사

보관된 고정 평가 기사 7건에 기존 후보 가중치·기존 벡터·마진 0.15를 그대로 적용했다. API 호출은 0회다. 이전 보고서를 덮어쓰지 않고 별도 로컬 보고서 `heldout-independent-neutral.local.json`에 기록했다.

| 항목 | 기존 계약 | 실험 계약 |
|---|---:|---:|
| 평가 기사 | 7 | 7 |
| 모든 비광고 문장의 벡터 확보 | 6 | 6 |
| 좌표에 영향을 주는 미확정이 없는 기사 | 0 | 2 |
| 일부 쟁점의 관측 좌표가 있는 기사 | 2 | 2 |
| 기존 기준의 대표 좌표 산출 가능 기사 | 0 | 0 |

미확정이 사라진 두 기사는 방향 문장이 없어 대표 좌표를 산출하지 않는다. 찬반 문장이 있는 기사에는 실제 유보가 남아 있다. 하나의 문장은 학습 파티션과 동일한 정규화 텍스트여서 평가 벡터 재사용에서 제외했다. 이번 결과는 이미 관찰한 고정 평가 집합의 회귀 진단이며 새로운 독립 정확도나 완성 증거가 아니다.

## 운영 상태와 남은 작업

배포 `/api/capabilities` 확인: HTTP 200, `biasModel.ready=false`, 주제 목록은 비어 있다. 연구 계약은 release 스키마/평가 재현과 독립 기사 검증을 마치기 전 운영 경로에 연결하지 않는다. 기존 연구 원본의 이용 검토가 미완료이고, 같은 사건·매체별 3건·2개 매체의 비교 표본도 부족하다. 운영 아티팩트는 계속 null이다. 승인 값·성능 수치·비교 표본을 임의로 만들지 않았다.

사용자가 창을 다시 연 후에도 Browser 선택은 `Browser is not available: iab`, 연결 목록은 `[]`였다. 화면 조작이나 실제 기사 입력 UI 검사는 수행하지 못했다. 다른 브라우저로 대체하지 않았다.

다음 구현은 문맥을 이용한 방향·쟁점·화자 분류 개선, 이용 근거가 확인된 학습/독립 평가 자료 확보, 새 집계 계약의 release 재현, 같은 사건의 다매체 표본 확보 순서다. 현재 결과를 배포 편향 기능 완성으로 보고하지 않는다.
