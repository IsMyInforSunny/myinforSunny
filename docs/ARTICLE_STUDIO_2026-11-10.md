# 2026-11-10 기사 중심 UI와 분석 구조 수정

## 반영한 방향

- 노란색 배경, 왼쪽 상시 기사 입력과 원문, 오른쪽 가로 지표, 하단 관련 기사 배치로 교체했다.
- 교육·과학·경제·사회·문화·건강·정치 등 논점이 있는 기사를 대상으로 본문 입장을 추출한다.
- 댓글 입장과 본문 입장을 별도 계약으로 분리했다. 본문 인용과 비교 명제가 확인된 결과만 관점 막대에 표시한다.
- 기본 관점은 찬성·반대·복합의 범주 분류다. 막대 위치로 강도나 확률을 주장하지 않는다. 정치 좌우는 별도 선택이다.
- 자극은 공포 유도·과도한 단정, 공격성은 인신공격·집단 일반화·조롱·위협으로 각각 집계한다. 기본 분모는 본문이며 댓글 포함을 선택할 수 있다.
- 신뢰의 기본 지표는 출처 명시 비율로 선택했다. 외부 자료 대조의 가중 근거는 보조 결과로 분리했다.
- 같은 명제에 대한 기사 입장을 비교해 본문과 같은 관점·다른 관점을 구분한다. 원문과 인용이 확인된 기사만 추천한다.
- 처리 서비스·실행 모델·추가 조사 상태·분모·미판정 범위를 화면에 노출했다. 안내 페이지와 내보내기 메타데이터도 맞췄다.

## 확인한 구조적 문제와 현재 한계

1. 배포용 bias-model.json은 null이다. SVM 좌우 좌표 계산과 거리 기반 추천은 준비되지 않았다. PCA는 연구 코드에만 있으며 제품 추천에 연결되어 있지 않다.
2. 기존 정치 비교 매체 구분을 일반 기사의 논점 분석 전체에 적용할 수 없다. 정치 좌우 선택에만 한정했다.
3. 기본 제공자는 Groq의 openai/gpt-oss-120b다. 직접 OpenAI API를 호출하는 구조와 구분해야 한다. 실제 제공자는 런타임 설정에 따라 화면에 표시한다.
4. 본문 분석은 한 번의 모델 호출이다. 본문 입장도 그 호출에서 추출한다. 추가 조사는 계획과 대조를 순차 실행하며 호출 사이 약 61초 대기를 유지한다. 사실 주장 5개와 관점 질문 1개이면 초기 분석을 포함해 최대 8회 호출과 누적 약 427초의 대기가 가능하다.
5. NVIDIA 조사 클라이언트의 60초 제한을 서버 처리 시간에 맞는 660초로 보완했다. 공급자 한도와 일일 예산 보호는 유지했다.
6. 과거 공개 기사 분석의 INVALID_MODEL_OUTPUT 원인은 확정되지 않았다. JSON 해석·스키마 검증·공급자 거절·출력 잘림을 구분하는 고정 형식 진단을 추가했다. 원문·키·임의 속성명·오류 원문은 기록하지 않는다.
7. 독립 사람 평가와 실제 서비스 분석 성공률 검증은 남아 있다. 가상 예시와 자동 검사를 실제 정확도 평가로 간주하지 않는다.

## 검증

- TypeScript 검사 통과.
- 전체 자동 검사 822개 통과, 선택적 검사 13개 건너뜀.
- 생산 빌드 성공 후 데스크톱 1440px, 모바일 390px에서 가상 예시로 화면 확인.
- 상시 입력, 교육 논점의 복합 관점, 분석 근거 창, 정치 모델 준비 상태, 본문 수정과 이전 결과 경고 확인.
- 로컬 capabilities에서 실시간 분석·검색·취득 비활성 확인. 브라우저 오류 0개.
- 실제 유료/외부 모델 호출을 통한 품질 검증은 수행하지 않았다.

## 후속 검증 범위

- 새 진단을 통한 실제 기사 모델 형식 실패 원인 확인과 공급자 응답 재검증.
- 정치 이외 여러 분야를 포함한 독립 라벨 평가 및 찬반 명제·인용의 품질 측정.
- 사용 권한이 확인된 기사 데이터로 모델 학습·분리 평가 후 SVM/PCA 제품 연결 여부 결정.
